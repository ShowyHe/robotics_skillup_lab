# robotics_skillup_lab

一个面向机器人开发成长的结构化学习仓库，用于系统提升 Nav2、ROS2、Linux、Python、C++、工程化调试、源码阅读、插件开发、研究复现与求职表达能力。

## 当前定位

当前处于从“能跑通、能排障”向“能解释系统、能做工程、能阅读源码、能进入二次开发”过渡的阶段。

这个仓库不是零散笔记集合，而是一条长期学习主线。目标不是短期打卡，而是逐步形成：

- 独立开发能力
- 工程交付能力
- 源码理解与二次开发能力
- 研究复现与论文实验能力
- 面试与作品集表达能力

## 当前重点

当前主任务：

- `docs/01_nav2_foundation_7d/`

先用 7 天把 Nav2 的概念、模块边界、CLI 证据链、源码入口和闭卷复盘机制夯实。

## 工作方法

全仓库长期遵循以下原则：

1. 先官方，后二手资料  
2. 先能解释，再求能写代码  
3. 先可复现，再谈优化与创新  
4. 每个阶段必须留下文档、命令、错误、修正和结论  
5. 所有学习都尽量转化为可验证、可复盘、可展示的成果

## 长期目标

通过这个仓库逐步完成以下跃迁：

- 从会跑 demo 到会解释系统
- 从会解释系统到会做工程交付
- 从会做工程到会读源码与做插件
- 从会读源码到会做研究复现与实验
- 从学习者成长为可独立承担任务的机器人开发工程师
