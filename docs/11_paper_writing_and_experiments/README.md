# 11｜原创方法、实验叙事与论文管线

## 定位

本目录虽然名称仍为 `paper_writing_and_experiments`，但实际内容不再是“写写论文总结”或“记录实验结果”，而是正式进入原创研究工作层。

目标不是继续复现别人的工作，而是逐步具备：

- 从工程问题抽象研究问题
- 提出方法假设
- 设计原型与迭代路线
- 做 ablation、error analysis、negative results
- 建立 claim-evidence map
- 组织 figure / table / storyline
- 写出具有研究结构感的论文骨架

## 为什么这个模块必须存在

前面已经做了：

- 系统与架构理解
- 运行机制理解
- 实验基础设施
- 核心实现与扩展点进入
- 研究级评测和 benchmark
- 文献矩阵与 baseline 复现

这时候如果还停留在“继续复现”，上限就会被卡住。  
必须进入：

- 问题重定义
- 原创方法假设
- 研究叙事与证据组织
- 面向高水平成果输出的工作方式

## 模块目标

完成本模块后，应逐步具备以下能力：

- 能把工程问题抽象成研究问题
- 能设计方法假设与原型路线
- 能用 ablation 拆贡献，而不是把一坨东西一起跑
- 能做 error analysis 与 negative results 归纳
- 能把结论和证据一一对应起来
- 能组织论文骨架、图表和章节叙事

## 模块主要产物

本模块后续应重点沉淀：

- 研究问题定义文档
- 方法假设与原型设计文档
- 原型 v1 / v2 记录
- ablation 设计与执行记录
- error analysis 与 negative results archive
- claim-evidence map
- figure / table skeleton
- 论文骨架与章节草稿
- 模块总结
- 模块总验收
- 证据索引

## 学习与执行方式

本模块采用 Sprint 机制推进，每个 Sprint 按以下节奏执行：

1. 问题定义与方法图谱建立  
2. baseline、实验结果与论文叙事证据采集  
3. 方法、实验、相关工作与图表逻辑深读  
4. 原型实现、实验循环、ablation、写作动作  
5. 总结、闭卷与复盘  

每天必须保留：

- 今天聚焦的研究问题或方法问题
- 今天的关键实验或图表证据
- 今天的实现或写作动作
- 今天最容易混淆的概念
- 当天闭卷问答
- 明日衔接点

## 验收标准

完成本模块时，至少应满足以下条件：

- 能清晰定义一个值得研究的问题
- 能形成方法假设并做最小原型
- 能做消融、失败分析和负结果归档
- 能把图表、表格、章节和结论组织成论文骨架
- 能通过闭卷稳定表达“我的方法在解决什么、凭什么成立、还有什么边界”

## 与后续模块的关系

本模块直接通向长期成果沉淀：

- 为 `12｜总归纳、融会贯通与长期知识系统` 提供旗舰成果候选、知识树节点和长期研究主线
- 也是从“研究型开发者”走向“高水平成果产出者”的关键一层
