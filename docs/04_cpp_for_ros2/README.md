# 04_cpp_for_ros2

## 定位

本目录用于建立面向 ROS2、Nav2、插件开发和工程实现的 C++ 基础。

目标不是泛泛学一遍 C++，而是为后续源码阅读、插件理解和二次开发铺路。

## 核心目标

逐步掌握以下内容：

- C++ 基础语法
- 类与对象
- 构造、析构、引用、指针、const
- STL 常用容器
- 头文件与源文件组织
- CMake
- 面向对象设计基础
- RAII 与资源管理意识
- rclcpp 基础
- 为 pluginlib 做前置准备

## 为什么必须单独立项

以后真正进入 ROS2 / Nav2 的核心开发层，绕不开这些场景：

- 阅读 C++ 源码
- 看懂类结构与接口定义
- 理解 server、plugin、node 的实现关系
- 修改参数逻辑、控制逻辑或插件行为
- 处理性能更敏感的实现

如果 C++ 不稳，你会长期停留在“会跑系统但不敢碰核心代码”的阶段。

## 学习原则

本目录不追求空泛刷题，而追求：

- 每个语法点都能落到 ROS2 / 工程背景
- 每次学新东西时，知道它后面会用在什么地方
- 逐步向 rclcpp、pluginlib 和源码阅读靠拢

## 建议范围

- C++ 基础语法
- 函数、重载、作用域
- 类与对象
- 指针、引用、智能指针
- const、static、this
- vector、string、map
- 文件组织与 CMake
- 简单 ROS2 C++ node
- 面向插件开发的前置理解

## 完成标准

完成本阶段时，应至少做到：

- 能读懂基础级别的 ROS2 C++ 示例
- 能写出简单、清晰、可编译的 C++ 小程序或 ROS2 小节点
- 能看懂一部分 Nav2 包内的类与接口声明
- 不再对 plugin、class、header/source 组织方式发怵
