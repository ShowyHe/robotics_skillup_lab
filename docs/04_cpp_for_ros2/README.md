# 04｜C++ / rclcpp / pluginlib 语言门槛突破

## 定位

本目录虽然名称仍为 `cpp_for_ros2`，但实际内容不再是普通 C++ 入门，而是面向 ROS2、Nav2 核心开发和插件扩展的语言门槛突破模块。

目标不是只会写几个基础程序，而是逐步跨过下面这些真正关键的门槛：

- 所有权与生命周期
- RAII 与资源管理
- 接口、继承、多态、虚函数
- 模板与现代 C++ 风格
- rclcpp 节点与执行模型
- pluginlib 所依赖的语言前置能力

## 为什么这个模块必须存在

当前已经有了一定的 ROS2 与系统视角，也做过少量最小 C++ / ROS2 接触。  
但是如果想进入 Nav2 核心层，仅靠 Python 和配置理解是远远不够的。

如果不认真跨过这一步，后面会被卡死在：

- 看得懂运行结果，但进不了实现层
- 知道有扩展点，但不敢碰插件
- 会看一点头文件，但看不懂类关系和生命周期
- 一碰到 shared_ptr、virtual、模板、callback group、executor 这些东西就开始腿软

这一步不是为了“学语言本身”，而是为了拿到进入 ROS2 / Nav2 核心代码层的门票。

## 模块目标

完成本模块后，应逐步具备以下能力：

- 能理解现代 C++ 在机器人系统中的基本风格
- 能解释对象、生命周期、所有权和资源管理在 ROS2 里的意义
- 能读懂基础到中等难度的 ROS2 / Nav2 C++ 代码
- 能实现基础级 `rclcpp` 节点
- 能理解 pluginlib 所依赖的接口、多态、虚函数和装载机制前置语义

## 模块主要产物

本模块后续应重点沉淀：

- C++ 深潜笔记
- 关键语言机制说明文档
- 最小到中等复杂度 C++ / ROS2 示例
- 最小 `rclcpp` 节点
- plugin 风格接口骨架理解文档
- 模块总结
- 模块总验收
- 证据索引

## 学习与执行方式

本模块采用 Sprint 机制推进，每个 Sprint 按以下节奏执行：

1. 问题定义与语言机制图谱建立  
2. 代码片段与真实实现证据采集  
3. C++ / rclcpp / pluginlib 相关实现深读  
4. 最小实现、重构、读写与对照实验  
5. 总结、闭卷与复盘  

每天必须保留：

- 今天的语言或实现层核心问题
- 今天看的代码片段或接口
- 今天最关键的语义理解
- 今天最容易混淆的概念
- 当天闭卷问答
- 明日衔接点

## 验收标准

完成本模块时，至少应满足以下条件：

- 能读懂中等难度 ROS2 / Nav2 C++ 代码
- 能解释 shared_ptr / unique_ptr / 生命周期 / 所有权
- 能解释接口、多态、虚函数为什么是插件基础
- 能写最小 `rclcpp` 节点并理解其执行模型
- 能把语言理解与后续源码、插件、扩展联系起来
- 能通过闭卷稳定表达这些高频概念

## 与后续模块的关系

本模块是进入核心层的语言门票：

- 为 `05｜Nav2 源码入口、改造与扩展点` 提供源码进入能力
- 为后续高级插件设计和定制化打语言基础
- 为 `08｜大代码库阅读方法与架构重建` 提供实现层阅读能力
