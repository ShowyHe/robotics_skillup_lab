# 01_nav2_foundation_7d

## 定位

本目录用于用 7 天时间系统夯实 Nav2 基础，建立清晰的模块脑图、命令验证习惯、闭卷输出机制和复盘方式。

这不是“看几篇文档”的目录，而是一次有明确验收标准的基础校准训练。

## 要解决的问题

当前已经能够跑通部分 Nav2 demo，也做过一定排障与脚本化工作，但仍存在以下典型问题：

- 知道现象，但未必总能说清原理
- 知道命令，但未必总能解释命令在验证什么
- 懂一点 planner、controller、BT、lifecycle，但边界还不完全稳定
- 碰到源码包名、server、plugin 时容易混淆
- 学过的内容容易分散，缺少系统化对照与闭卷输出

本阶段的目标，就是先把这些基础地基打平。

## 学习目标

通过 7 天训练，逐步做到：

- 能说清 Nav2 核心模块的职责边界
- 能把官方概念、实际 demo、源码包名对应起来
- 能把关键 CLI 命令说清用途与证据
- 能通过闭卷测试把“看懂”转成“会说、会写、会复盘”
- 能识别当前最容易混淆的概念并纠正

## 文件说明

- `plan.md`：7 天总计划与每天重点
- `daily_summary_template.md`：每日总结统一模板
- `day1.md` ~ `day7.md`：每天的学习成果与闭卷修正记录

## 每日固定要求

每天必须包含：

1. 官方资料阅读  
2. 命令行验证  
3. 闭卷测试  
4. 原始回答与修正回答对照  
5. 最容易混淆概念复盘  
6. 与 7 天总目标的对应关系  

## 完成标准

完成本阶段，不是指 7 天过去了，而是至少满足以下条件：

- 能独立解释 action、lifecycle、planner、controller、costmap、BT 的角色
- 能说明自己当前 demo 的核心链路
- 能说出至少一版概念到源码包的映射
- 留下完整的 7 份 md 成果，可用于后续复习与面试准备

## 与后续衔接

本阶段结束后，应优先进入：

- `02_ros2_linux_fundamentals`
- `03_python_for_robotics`
- `04_cpp_for_ros2`

因为 Nav2 不是孤岛，后续工程能力一定要靠 ROS2、Linux、Python、C++ 一起顶住。
