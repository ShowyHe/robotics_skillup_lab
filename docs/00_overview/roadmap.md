# robotics_skillup_lab roadmap

## 总目标

围绕机器人开发与研究能力，建立一条长期、结构化、可复盘的成长路线，逐步实现：

- 能独立完成 Nav2 / ROS2 相关开发与排障
- 能编写与维护工程脚本、测试脚本、自动化工具
- 能阅读与定位关键源码
- 能进行小范围插件开发与系统定制
- 能复现论文、设计实验、组织图表与写作材料
- 能以工程证据链形式进行作品集展示与面试表达

## 阶段划分

### 第一层：基础夯实层
- 01_nav2_foundation_7d
- 02_ros2_linux_fundamentals
- 03_python_for_robotics
- 04_cpp_for_ros2

目标：从“会跑通”走向“能解释、能排查、能建立语言体系”。

### 第二层：工程能力层
- 05_nav2_engineering_drills
- 06_tooling_and_automation
- 07_testing_evaluation_and_debugging

目标：从“知道概念”走向“能做工程、能复现、能交付”。

### 第三层：源码与二次开发层
- 08_source_code_reading
- 09_plugins_and_customization

目标：从“会使用系统”走向“能理解、能修改、能扩展系统”。

### 第四层：研究与职业输出层
- 10_research_reproduction
- 11_paper_writing_and_experiments
- 12_portfolio_and_interview

目标：从“会实现”走向“会研究、会表达、会证明自己”。

## 当前优先级

当前优先级排序：

1. 01_nav2_foundation_7d
2. 02_ros2_linux_fundamentals
3. 03_python_for_robotics
4. 04_cpp_for_ros2
5. 05_nav2_engineering_drills
6. 06_tooling_and_automation
7. 07_testing_evaluation_and_debugging

08 之后属于中期推进，不急于一口吃下。

## 判断标准

每进入下一个阶段前，都要问自己三个问题：

1. 前一阶段的核心概念是否已经能讲清  
2. 前一阶段是否已经留下可复盘成果  
3. 当前新增内容是在补能力，还是在制造热闹  

如果只是“看起来很努力”，那就不算进步。
