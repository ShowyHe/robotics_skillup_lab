# 00_overview

## 定位

本目录用于定义整个仓库的总路线、阶段边界和长期目标。

这里不放零散知识点，不写某一天学了什么，而是回答三个核心问题：

1. 这个仓库为什么存在  
2. 现在处于哪一个阶段  
3. 下一步应该往哪里走  

## 目录职责

本目录负责：

- 维护长期学习路线
- 维护各阶段之间的先后关系
- 防止学习过程东一块、西一块，失去主线
- 给后续新增模块提供统一的判断标准

## 使用原则

后续每新增一个阶段目录，先回到这里检查两件事：

1. 这个新目录是否真的属于当前成长路径  
2. 它是在补基础、补工程、补源码，还是补研究输出  

如果说不清，就先不要加。  
目录不是摆设，目录代表能力台阶。

## 当前判断

当前最优先的是：

- `01_nav2_foundation_7d`
- `02_ros2_linux_fundamentals`
- `03_python_for_robotics`
- `04_cpp_for_ros2`

这四层决定后面工程能力能不能站稳。

## 维护要求

本目录中的内容应当尽量稳定，不频繁修改。  
只有当整体学习方向发生变化，或者阶段优先级需要调整时，才更新这里。
