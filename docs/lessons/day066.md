## A. Foundation（01–09）

### 01. 2D A* 的不足
普通网格以 \`(x,y)\` 为状态，只保证图上位置连接；路径出现瞬时90°转角时，不能自动保证汽车式运动模型可执行。

### 02. Configuration / State
二维平面位姿配置 \`q=(x,y,θ)\`（x,y:m, θ:rad）。完整动态 State 可再包括速度/其他状态。机器人前方定义为机体 +x，地图逆时针 yaw 为正，所有公式依此约定。

### 03. Heading 的必要性
同一位置 \`(x,y,0)\` 与 \`(x,y,π/2)\` 的下一次合法运动、Footprint 朝向不同；位置相同不代表搜索状态等价。

### 04. Continuous Pose / Discrete Key
连续姿态 \`q=(x,y,θ)\` 由运动学积分计算；\`k=(i_x,i_y,i_θ)\` 为栅格、航向 Bin 构成的搜索索引，便于队列管理和去重。不同连续 Pose 可能映射同一 Key；实现通常保留代表节点，导致量化近似而非二者完全相同。

### 05. Holonomic / Nonholonomic
Holonomic（完整）约束可积成位置/构型约束；Nonholonomic（非完整）约束的典型例子为不可侧滑汽车/差速机器人，其机体横向瞬时速度为零，但可经前进/后退/转弯的组合最终抵达侧方位置。不可直接侧移 ≠ 无法抵达侧方。能原地旋转的差速底盘仍可能是非完整系统。

### 06. Nonholonomic Constraint 的公式
若机体沿 \`[cosθ,sinθ]^T\` 前行，机体侧向单位向量为 \`[-sinθ,cosθ]^T\`。无侧滑时 \`-sinθ·x_dot+cosθ·y_dot=0\`，约束的是瞬时速度方向。

### 07. Unicycle Kinematics
\`\`\`text
x_dot = v cosθ
y_dot = v sinθ
θ_dot = ω
\`\`\`
v:m/s，ω:rad/s，位移以 m、θ 以 rad。此无侧滑模型是常见规划简化，并非所有机器狗必然适用。

### 08. Curvature / Turning Radius
非零前进速度时 \`κ=ω/v\`（有符号曲率，m⁻¹）；\`R=|v|/|ω|=1/|κ|\`（m）。\`v=0.4m/s,ω=0.8rad/s\` ⇒ \`κ=2m⁻¹,R=0.5m\`。汽车自行车模型 \`κ=tanδ/L\`，\`R_min=L/tan(|δ_max|)\`。原地旋转 \`v=0\` 是特殊情况，不能当作一般前进圆弧曲率。

### 09. Primitive / Heading Bin 词义区分
Heading Bin 数量是方向离散区间数；Motion Primitive 数量是从当前状态尝试的运动动作数。72 个朝向 Bin 并不等于72个邻居；6 个候选 Primitive 意味着每次尝试6段运动，展开后再归类到航向 Key。

## B. Core（10–25）

### 10. Motion Primitive
具有运动学含义的一段有限运动，例如 forward-straight/left/right、reverse-straight/left/right。一般可通过恒定控制输入或预先定义的轨迹段产生。

### 11. Primitive 不是单个 Grid Edge
一次 \`q0→q1\` 可包含整段连续曲线 \`q(t),0≤t≤T\`。碰撞检查必须覆盖过程，不能只检查终点。

### 12. Forward Euler Rollout
\`\`\`text
x_{k+1}=x_k+v cosθ_k Δt
y_{k+1}=y_k+v sinθ_k Δt
θ_{k+1}=θ_k+ω Δt
\`\`\`
例如 \`q0=(0,0,0),v=0.5m/s,ω=0,T=2s\` ⇒ \`q1=(1m,0,0)\`。

### 13. Constant-twist Exact Integration
当 \`ω≠0\`、控制恒定：
\`\`\`text
x1=x0+(v/ω)[sin(θ0+ωT)-sinθ0]
y1=y0-(v/ω)[cos(θ0+ωT)-cosθ0]
θ1=θ0+ωT
\`\`\`
\`v=0.4,ω=0.5,T=1,q0=(0,0,0)\` ⇒ \`x≈0.384m,y≈0.098m,θ=0.5rad\`，不同于大步长Euler的 \`(0.4,0,0.5)\`。\`ω→0\` 应用直线极限。

### 14. State Key 示例
\`r=0.1m, N_θ=72\` 时每方向 Bin 5°，连续位姿 \`(1.26,2.43,θ)\` 可映射 \`(i_x=12,i_y=24,i_θ)\`（采用下取整示意）。角度要归一化处理 0 与 2π 等价。

### 15. Pose Quantization Risk
\`(1.21,2.42,10°)\` 和 \`(1.29,2.48,14°)\` 可能落同一 Key，但在 \`x'=x+vcosθΔt\`、\`y'=y+vsinθΔt\` 中，x/y/θ 不同会给出不同结果。索引用于搜索管理，Pose 用于运动学传播。

### 16. Hybrid A* Search
按 A* 取最小 \`f=g+h\`；对每种 Primitive 按运动学传播、做整段可行性/碰撞检查、增加代价、离散化生成 Key、更新 g/parent/open；结束时恢复 Primitive Chain。

### 17. Forward / Reverse Signs
\`v>0\` 前进、\`v<0\` 倒车；倒车不意味着机体朝向反转180°，θ 与移动方向应区别保存。

### 18. Cost / Reverse / Steering / Gear-change
Primitive Cost 可包含距离、反向行驶、转向、换挡等非负惩罚。若转换代价依赖先前驱动方向，必须在节点 State/Cost bookkeeping 中保留足够的历史/模式信息，否则简单 \`(x,y,θ)\` 去重可能丢失正确未来成本。

### 19. Heuristic
欧氏距离通常是距离型 Cost 的简单下界；Obstacle-aware（考虑障碍但简化运动）和 Kinematics-aware（考虑运动但忽略障碍）也可提供下界。二者对同一目标函数均可采纳时，\`h=max(h_obs,h_kin)\` 仍可采纳，不能随意相加。

### 20. Discretization / Optimality Boundary
Hybrid A* 的搜索质量取决于 xy resolution、heading bins、primitive length、所保留连续 Pose、碰撞检查及启发函数。**离散/近似搜索图中最优**不代表连续世界严格全局最优。

### 21. Analytic Expansion
搜索接近目标时，可尝试用解析运动学连接将 \`q_current\` 直接连到 \`q_goal\`，减少后续离散扩展；必须进行连续或保守采样的碰撞与约束验证，且依具体算法的接受条件。

### 22. Dubins
给定最小转弯半径、两端位姿和前进方向约束，使用直线 S 与最大曲率 L/R 圆弧的组合求前进-only 曲率约束连接；不允许倒车。

### 23. Reeds–Shepp
在类似有曲率界条件下允许前进与倒车，因此与 Dubins 的关键区别是支持 reverse；不代表已满足全部速度/加速度/地面力学限制。

### 24. Primitive / Analytic Path Swept Collision
\`F(q(t))∩O=∅\` 应沿整段运动成立。仅起终点 Footprint 无碰撞不保证中间不碰撞；不因运动学连接成功就跳过254障碍检查。

### 25. State Lattice vs Hybrid A*
State Lattice 通常预定义连接离散状态格的合法 Primitive 网络；Hybrid A* 往往保留连续计算 Pose 及离散索引。二者均可使用 A*；区别主要在节点和转移如何构造，不是“用不用A*”。

## C. Advanced / Owner（26–29）

### 26. Kinodynamic Boundary
仅 \`(x,y,θ)\` 的几何/运动学搜索缺少当前速度和加速度/制动约束。同位姿但不同 v 的制动距离可不同；动态规划可增加 \`s=(x,y,θ,v,ω,...)\` 以及加速度/输入传播，但具体状态要与真实执行系统匹配。

### 27. Braking / Latency
理想匀减速：\`d_stop=v²/(2a_max)\`，\`t_stop=|v|/a_max\`；\`v=0.4,a_max=0.2\` ⇒ 0.4m/2s；延迟 \`t_delay=0.1s\` 且期间速度不变，额外行驶 0.04m，合计约0.44m。速度提高三倍，理想制动距离提高9倍。

### 28. Path ≠ Trajectory
几何路径可能满足朝向/曲率和碰撞限制，但不指定每个点何时到、速度/加速度；Timed Trajectory / Controller/MPPI与真实反馈还要另行保证。

### 29. Owner：Motion Model × Real Robot
Nav2 Smac Hybrid-A* 阅读框架：State/Key、Motion Model、Primitive、Cost、Heuristic、Collision、Analytic Expansion、输出。机器狗可能支持原地转向、侧移等，不可默认汽车式固定非零最小转弯半径。若机器人实际支持原地转向而规划模型禁止，窄道或 Goal Yaw 调整可能出现绕大弯/无法终点对齐。先验证真实可执行运动集合，再对照模型与原语（源码具体实现未读取，不做定论）。
