## 2. 核心讲义

### 2.1 函数与导数

函数 `y=f(x)` 是输入到输出的关系。若 `p(t)` 是位置随时间变化的函数，导数描述当前位置对时间的瞬时变化率：

```text
v(t) = dp(t)/dt
     = lim(Δt→0) [p(t+Δt)-p(t)]/Δt
```

`p(t)∈R²` 时，`v(t)∈R²`，例如 `p=[x,y]^T`，`v=[dx/dt,dy/dt]^T`。位置、速度、加速度分别对应 `p`、`dp/dt`、`d²p/dt²`。一维位置变化是有符号位移，不应一律称为路程。

有限时间的比值是平均变化率；观察窗口趋近零得到瞬时导数。几何上，两个点的割线逐渐逼近当前点的切线，其斜率就是导数。导数的核心是局部敏感度，不是单纯的求导口诀。

### 2.2 微分与局部近似

对于标量函数 `y=f(x)`：

```text
dy = f'(x) dx
Δy ≈ f'(x) Δx
```

`dx` 是自变量的微小变化，不一定是时间；`dy` 是线性微分，近似的是实际有限变化 `Δy`。例如 `y=x²`，在 `x=10`、`Δx=0.01` 时，`Δy≈20×0.01=0.2`，实际为 `0.2001`。

若自变量是时间，则 `dp≈v dt`。若自变量是航向角，则 `dθ` 是角度变化（rad），`dθ/dt` 才是角速度（rad/s）。不要把微分、导数和积分混为一谈。后续多变量形式是 `Δy≈JΔx`，Day15 再正式学习。

### 2.3 数值求导与噪声

真实机器人只有有限采样。用可靠时间戳计算：

```text
Δt_k = t_k - t_(k-1)
v_k ≈ [p_k-p_(k-1)] / Δt_k
```

这是有限差分近似导数，不是积分。间隔太大时，局部变化被平均，离散近似误差可能增加；间隔太小时，位置测量噪声之差也被除以小时间间隔。若 `p_m=p_true+n`，差分噪声为 `[n_k-n_(k-1)]/Δt_k`。因此更高采样率不自动保证差分速度更准确。

本日计算：`p1=1.00m,t1=10.00s,p2=1.06m,t2=10.02s`，得到 `3m/s`。这是两帧差分估计，不保证真实瞬时速度等于 3m/s。

### 2.4 积分与 Forward Euler

积分把变化率随时间累计：

```text
p(t1)-p(t0) = ∫[t0,t1] v(t) dt
p_(k+1) ≈ p_k + v_k Δt_k
```

一维 `p` 单位 m，`v` 单位 m/s，`Δt` 单位 s；二维 `p,v∈R²`，`Δt∈R`，结果仍为二维位置。Euler 用区间起点的速度近似整个区间速度，因此是数值近似，不是普遍精确的物理定律。若区间内速度显著变化，误差可能增大。

本日计算：`p_k=2m,v_k=0.4m/s,Δt=0.05s`，得到 `p_(k+1)=2.02m`。若从静止开始以 `1m/s²` 匀加速 1 秒，真实位移为 `0.5m`，仅用起点速度的一步 Euler 则为 0，说明其近似边界。

### 2.5 Sampling、实际 dt 与频率

名义 10Hz 不等于每次实际间隔严格 0.1s。可靠时间戳为 12.00s 和 12.14s 时，积分应优先使用实际 `Δt=0.14s`。时间戳必须来自正确的时钟体系；不能混用不一致的时间基准。时间误差会直接进入积分误差。

传感器采样间隔与控制模型离散步长不是同一个概念。MPPI 的 `N=40,dt=0.05s` 对应 2s 预测时域；真实传感器积分应依据实际有效时间间隔。频率提高可改善时间分辨率和部分离散化误差，但不能自动消除 bias、noise、标定误差或模型误差。

### 2.6 累计误差、Wheel Odom 与 IMU

若速度测量 `v_m=v_true+b_v`，固定速度 bias 持续 T 秒，位置误差为：

```text
e_p = Σ b_v Δt_k = b_v T
```

不是每采样一次直接加一个不带 `dt` 的 bias。相同时间、正确积分下，100Hz 改为 1000Hz 不会使固定 bias 误差自动增加十倍。

若加速度测量存在固定 bias `b_a`，初始速度与位置误差为零，则：

```text
e_v(t)=b_a t
e_p(t)=0.5 b_a t²
```

速度误差线性增长，位置误差按时间平方增长。`b_a=0.05m/s²,T=10s` 时，分别为 `0.5m/s`、`2.5m`。速度不会维持常数。

求导容易把高频测量噪声放大；积分容易累计持续 bias。两者都是简化工程直觉，不代表积分不受随机噪声影响。Wheel Odom 会受轮径误差、打滑、反馈与时间误差影响；IMU 需要积分得到速度、再积分得到位置，不能仅靠高频就得到可靠绝对位置。后续融合模块将讨论其他传感器约束。

## 3. 今日真实答题与纠错

### 已稳定掌握

- 能解释位置随时间变化产生速度，并正确计算有限差分速度。
- 能计算一维 Euler 更新，说明起点速度近似假设。
- 能依据实际时间戳选择 `dt`，不盲用名义频率。
- 能解释高频不等于准确度，持续 bias 会累计。
- 能计算固定加速度 bias 的速度与位置误差，并指出线性、平方增长趋势。

### 暴露的错误理解

1. 把 `dp/dt` 与离散差分、积分混在一起；已纠正为连续导数、有限差分近似导数、积分累计三类操作。
2. 把一般微分 `dx` 固定理解成时间；已纠正为自变量变化，只有 `x=t` 才是时间微分。
3. 把 `dθ` 说成航向角速度；已纠正为角度变化，`dθ/dt` 才是角速度。
4. 把求导时小 `dt` 放大噪声的规律错误套到积分；已纠正为积分误差需乘 `dt`，高频不自动增加固定 bias 的总累计量。
5. 认为固定加速度 bias 使速度误差保持常数；已纠正为速度误差线性增长，位置误差平方增长。
6. 曾把固定速度 bias 积分写成“每 Hz 加一次 bias”；已纠正为 `Σb_vΔt_k=b_vT`。
7. 固定速度 bias 持续 10s 的位置误差计算数值正确，但曾写成 `1m/s`；正确单位为 `1m`。

### 定向复测证据

- `dp/dt`：回答为导数、二维；PASS。
- `dx` 不一定是时间：判断正确；航向角例题仍把 `dθ` 误称角速度，纠正后保留 Review。
- `b_v=0.1m/s,T=10s`：数值 1 正确，单位误写 m/s；正确位置误差为 1m。
- `b_a=0.05m/s²,T=10s`：回答 `0.5m/s,2.5m`，线性与时间平方增长；PASS。
