## 2. Random Variable vs Observation

随机变量（Random Variable）X：
- 用来描述机器人未知的真实状态可能是什么；
- 不是某一个具体预测值。

观测值（Observation / Measurement）z：
- 传感器实际返回的一次测量。

核心边界：

X = 未知状态的随机变量
z = 实际收到的观测值

## 3. Probability Distribution

概率分布描述各种可能状态各有多可信。

离散情况：

P(X=x)

连续情况使用概率密度：

p(x)

## 4. Joint / Marginal Probability

联合概率（Joint Probability）：

P(A,B)

表示 A 与 B 同时发生。

边缘概率（Marginal Probability）通过把另一个变量的所有可能情况汇总掉得到，例如：

P(X=x) = sum_z P(X=x,Z=z)

## 5. Conditional Probability

条件概率：

P(A|B) = P(A,B) / P(B)

表示“已知 B 已发生时，A 发生的概率”。

Hard Gate：

P(A|B) 与 P(B|A) 一般不相等，不能直接交换条件方向。

## 6. Independence

若 A 与 B 独立：

P(A,B)=P(A)P(B)

并且：

P(A|B)=P(A)

机器人多传感器场景不能机械假设独立；共享环境、共享传感器或相邻帧可能存在相关性。

## 7. Bayes Theorem（贝叶斯定理）

P(x|z) = P(z|x)P(x) / P(z)

对应：

- P(x)：Prior（先验）
- P(z|x)：Likelihood（似然）
- P(x|z)：Posterior（后验）
- P(z)：Evidence（证据 / 归一化项）

核心机器人解释：

Prior + Sensor Likelihood → Posterior

## 8. Likelihood vs Posterior

Likelihood：

P(z|x)

问题：

“假设状态 x 是真的，当前观测 z 合不合理？”

Posterior：

P(x|z)

问题：

“已经看到 z 后，现在状态 x 有多可信？”

两者不能混用。

## 9. Evidence

P(z) 用于归一化：

P(z)=sum_x P(z|x)P(x)

使所有 Posterior 概率总和为 1。

## 10. Sequential Update

机器人连续接收传感器数据：

Posterior_t
→ Next Prior
→ New Measurement
→ Posterior_(t+1)

核心：

这一轮后验会成为下一轮继续推断的先验基础。

后续 Kalman Filter / EKF 会把这条思想进一步拆成 Prediction + Measurement Update。

## 11. Robot Connection

例如定位：

Prior：
来自上一时刻状态、里程计、IMU、运动模型。

Measurement：
GPS / LiDAR / Camera 等新观测。

Likelihood：
描述假设机器人处于某状态时，产生该观测的合理程度。

Posterior：
结合先验和新观测后的新状态 Belief。
