## 6. 为什么需要 Activation（激活函数）

如果连续多层只有线性 / 仿射变换：

[
h=W_1x+b_1
]

[
y=W_2h+b_2
]

可以合并成：

[
y=W'x+b'
]

因此再多层也只是一个仿射变换。

加入 ReLU（Rectified Linear Unit，修正线性单元）等非线性激活后，模型才能表达更复杂关系。

## 9. Forward Pass（前向传播）

```text

→ Layer
→ Activation
→ Layer
```

## 10. Training 与 Inference

Training（训练）：

```text
Data
→ Forward
→ Loss
→ Backward
→ Parameter Update
```

Inference（推理）：

```text
Data
→ Forward
→ Prediction
```

推理阶段通常不更新参数。
