## 2. Precision / Recall

Precision（精确率）：

Precision = TP / (TP + FP)

回答“模型说检测到的目标中，有多少是真的”。

Recall（召回率）：

Recall = TP / (TP + FN)

回答“真实存在的目标中，有多少被检测出来”。

通常提高 Confidence Threshold 会使 FP 减少、Precision 上升，但 FN 可能增加、Recall 下降。

## 3. Confidence Threshold vs IoU Threshold

Confidence Threshold（置信度阈值）：
- 控制模型分数达到多少才保留 Detection。

IoU Threshold（交并比阈值）：
- 在评估中控制 Prediction Box 与 Ground Truth Box 重合到什么程度才算正确匹配。

二者职责不同。

## 4. AP / mAP

对于一个类别，改变 Confidence Threshold 会得到不同的 Precision / Recall 工作点，形成 Precision-Recall Curve（精确率-召回率曲线）。

AP（Average Precision，平均精确率）用于概括单个类别跨多个阈值下的 PR 表现。

mAP（mean Average Precision，平均 AP）对多个类别的 AP 做平均；实际评测中还可能跨多个 IoU Threshold 进一步平均。

## 5. Segmentation Metrics

Pixel Accuracy（像素准确率）可能被大面积背景类别“冲高”。

对于关键小类别，应关注：
- Class IoU（类别交并比）
- mIoU（mean IoU，平均交并比）

例如 person 全漏，即使 Pixel Accuracy 很高，机器人系统仍可能不安全。

## 6. Depth Metrics

Depth 属于连续数值预测，可使用：

MAE = (1/N) * sum(|Z_hat_i - Z_i|)

也可看 RMSE 等。

整体平均误差较低，不代表近场障碍深度一定可靠。机器人系统可能需要专门关注 Near-field Depth Error（近场深度误差）。

## 7. Tracking 与 Data Association

Detection 是逐帧观测。

连续三帧都检测到 person，并不能自动说明已经完成 Tracking，因为系统还必须确认这些 Detection 是否对应同一个真实对象。

核心过程：

Detection_t <-> Track_(t-1)

这就是 Data Association（数据关联）。

关联可利用：
- Position（位置）
- IoU
- Appearance（外观）
- Motion Prediction（运动预测）

## 8. Track State

一个 Track 通常包含：
- ID
- Position
- Velocity
- Age
- Confidence
- Last Update / Freshness

因此 Detection 表示“这一帧看到了什么”，Track 表示“世界里我认为持续存在着哪个对象”。

## 9. Persistence / Timeout

Persistence（保持）：
- 短时间漏检后仍保留 Track，避免 World Model / Costmap 在有无障碍之间闪烁。

Timeout（超时）：
- 长时间没有新观测后删除 Track，避免 Ghost Obstacle（幽灵障碍）。

二者必须配合。

## 10. Stale Perception

Track 仍存在，不代表它的位置仍然可靠。

动态目标经过一段时间后可能已经移动，因此必须检查 Freshness（新鲜度）。

核心：

Information Exists != Information Is Fresh

## 11. Model Score vs Robot Decision

Model Confidence Score（模型置信分数）不是 Robot Safety Decision（机器人安全决策）。

机器人决策还应结合：
- Distance
- Relative Motion
- Freshness
- Depth Reliability
- Robot Speed
- Class / Risk

因此低于某个模型阈值的近场高风险目标，也不能机械忽略。

## 12. Component Metric vs End-to-End Metric

Component Metric（组件指标）例如：
- mAP
- mIoU
- Depth MAE
- Tracking Accuracy

End-to-End Metric（端到端指标）例如：
- Collision Rate
- Missed Obstacle Rate
- Emergency Stop Rate
- Navigation Success Rate
- Minimum Human Distance

核心：

Component Metric 变好，不代表 Robot Safety 一定变好。

## 13. Perception→Robot Debug Chain

当 Detector 明明检测到人，但机器人仍然差点撞上，应沿链排查：

Detection
→ Depth
→ Calibration/TF
→ Tracking
→ Freshness
→ World/BEV
→ Costmap
→ Planner

mAP 变好但机器人更危险，可能来自 Detection 后面的 Depth、Calibration/TF、Tracking、Freshness、Cost Mapping、Costmap、Planner 或 Latency。
