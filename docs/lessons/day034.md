## 1. Classification vs Detection

Classification（分类）主要回答整张图是什么类别。

Detection（目标检测）回答图中有哪些目标、在哪里、属于什么类别。

Detection 最基本输出：

\[
\boxed{
Bounding\ Box + Class + Score
}
\]

Threshold（阈值）不是模型输出，而是后处理参数。

---

## 2. Bounding Box（边界框）

常见表示：

\[
(x_{min},y_{min},x_{max},y_{max})
\]

或：

\[
(c_x,c_y,w,h)
\]

例如：

\[
(100,50,300,250)
\]

则：

\[
w=200,\qquad h=200
\]

---

## 3. Score 与 Threshold

Score / Confidence（分数 / 置信表达）来自模型。

Threshold（阈值）由系统设置，用于决定候选检测是否保留：

\[
Score>Threshold
\Rightarrow
\text{保留}
\]

高 Score 不等于现实世界中同等程度的真实可信度。

---

## 4. IoU（Intersection over Union，交并比）

\[
\boxed{
IoU=
\frac{|A\cap B|}{|A\cup B|}
}
\]

其中：

\[
|A\cup B|
=
|A|+|B|-|A\cap B|
\]

范围：

\[
0\le IoU\le1
\]

IoU 衡量两个 Box 的几何重叠程度，不直接证明它们一定属于同一个真实目标。

---

## 5. IoU 计算

例如：

\[
|A|=120,\quad |B|=100,\quad |A\cap B|=40
\]

则：

\[
|A\cup B|=120+100-40=180
\]

\[
IoU=\frac{40}{180}\approx0.222
\]

---

## 6. TP / FP / FN

TP = True Positive（真阳性）：

真实有目标，模型也正确检测到。

FP = False Positive（假阳性）：

真实没有目标，模型却报出目标。

FN = False Negative（假阴性）：

真实有目标，模型却漏检。

机器人行人避障中，FN 特别危险，因为真实行人可能没有进入后续 World Model / Costmap / Planner。

---

## 7. Confidence Threshold（置信度阈值）

Threshold 太高：

\[
FN\uparrow
\]

真实目标可能被过滤掉。

Threshold 太低：

\[
FP\uparrow
\]

大量错误候选可能被保留。

因此 Threshold 是系统性能与安全权衡的一部分。

---

## 8. NMS（Non-Maximum Suppression，非极大值抑制）

当多个高分 Box 重复框住同一目标时，NMS 用于消除重复检测。

基本流程：
1. 选最高 Score 的 Box；
2. 计算它与其余 Box 的 IoU；
3. 删除与它高度重叠的低分 Box；
4. 对剩余候选继续处理。

---

## 9. Threshold 与 NMS 的区别

Confidence Threshold：

\[
\boxed{
\text{这个 Box 自己是否值得保留}
}
\]

NMS：

\[
\boxed{
\text{多个保留下来的 Box 是否重复检测同一目标}
}
\]

典型流程：

\[
Raw\ Prediction
\rightarrow
Threshold
\rightarrow
NMS
\rightarrow
Final\ Detection
\]

---

## 10. YOLO 基本结构

YOLO = You Only Look Once（只看一次）。

工程上先建立：

\[
\boxed{
Backbone
\rightarrow
Neck
\rightarrow
Head
}
\]

Backbone（骨干网络）：
提取视觉 Feature（特征）。

Neck（特征融合层）：
融合不同尺度 Feature。

Head（检测头）：
输出 Bounding Box / Class / Score。

---

## 11. Multi-scale Detection（多尺度检测）

不同目标在图像中的尺寸差异很大。

高分辨率 Feature 对 Small Object（小目标）更重要；较深层 Feature 提供更强语义和更大 Receptive Field（感受野）。

因此现代 Detector 常融合多尺度 Feature。

---

## 12. Small Object（小目标）问题

小目标经过多次 Downsampling（下采样）后，在 Feature Map 中可能只剩很少的空间单元。

因此容易出现：
- Feature 信息不足；
- Localization（框定位）困难；
- 背景干扰；
- 遮挡敏感；
- Recall（召回）下降。

---

## 13. Anchor / Anchor-Free

Anchor-based（基于锚框）：
预先设置不同尺寸和长宽比的参考框，再预测修正量。

Anchor-Free（无锚框）：
不依赖预定义 Anchor Shape，直接从 Feature 位置预测中心、边界或距离等。

两者只是 Bounding Box 产生方式不同，并不是“一个有 Box，一个没有 Box”。

---

## 14. 2D Detection 的几何边界

YOLO 输出的 BBox 本质仍然处于 Image Coordinate（图像坐标）中。

例如：

\[
bbox=(u_1,v_1,u_2,v_2)
\]

它不能直接得到机器人坐标系中的：

\[
(x,y,z)
\]

因为还缺 Depth（深度）或其他 3D 信息。

完整链：

\[
\boxed{
Pixel/BBox
\rightarrow
Depth
\rightarrow
Camera\ 3D
\rightarrow
TF/Extrinsic
\rightarrow
base\_link
\rightarrow
map
\rightarrow
Costmap
}
\]

因此：

\[
\boxed{
2D\ Detection\neq3D\ Obstacle
}
\]
