## 2. Day11 → Day12：Eigenvalue 与 Singular Value

Day11 的 eigen equation：

\[
Av=\lambda v
\]

其中：

- `A ∈ R^(n×n)`；
- `v ∈ R^n`，且 `v ≠ 0`；
- `λ ∈ R`（本日只讨论实数直觉）。

Eigenvalue 只描述那些经过 `A` 后仍沿原方向的特殊方向。

一般矩阵的最大长度拉伸不能直接看最大 eigenvalue。反例：

\[
A=\begin{bmatrix}0&10\\0&0\end{bmatrix}
\]

它的 eigenvalues 都为 0，但：

\[
A\begin{bmatrix}0\\1\end{bmatrix}
=\begin{bmatrix}10\\0\end{bmatrix}
\]

输入长度 1，输出长度 10。

因此一般矩阵的最大/最小长度拉伸由 **singular values** 描述，而不是 eigenvalues。

---

## 3. SVD 的形式与维度

对：

\[
A\in R^{m\times n}
\]

完整 SVD：

\[
A=U\Sigma V^T
\]

其中：

\[
U\in R^{m\times m},\qquad
\Sigma\in R^{m\times n},\qquad
V\in R^{n\times n}
\]

`U`、`V` 都是正交矩阵：

\[
U^TU=I,\qquad V^TV=I
\]

`Σ` 中的非负对角元素：

\[
\sigma_1\ge\sigma_2\ge\cdots\ge0
\]

称为 singular values。

---

## 4. SVD 的几何意义

对于输入：

\[
x\in R^n
\]

有：

\[
Ax=U\Sigma V^Tx
\]

从右往左理解：

### 4.1 `V^T`：换到特殊输入正交基

`V` 的列：

\[
v_1,v_2,\dots
\]

称为右奇异向量（right singular vectors）。

`V^T x` 表示把输入 `x` 分解到这些特殊输入方向上。

### 4.2 `Σ`：每个方向独立伸缩

每个右奇异方向对应一个 singular value：

\[
v_i \rightarrow \sigma_i
\]

`σ_i` 表示 `A` 对该输入方向的长度缩放倍数。

### 4.3 `U`：放到输出方向

`U` 的列：

\[
u_1,u_2,\dots
\]

称为左奇异向量（left singular vectors）。

最核心关系：

\[
\boxed{Av_i=\sigma_i u_i}
\]

解释：

> 单位输入方向 `v_i` 经过 `A` 后，可以改变方向到 `u_i`，长度变成 `σ_i` 倍。

这也是 SVD 与 eigen decomposition 的关键区别：

\[
Av_i=\lambda_i v_i
\]

要求输入/输出方向相同；而 SVD 允许：

\[
v_i\rightarrow u_i
\]

方向改变。

---

## 5. 最大/最小拉伸

奇异值按：

\[
\sigma_1\ge\sigma_2\ge\cdots\ge0
\]

排序。

因此：

\[
\boxed{\sigma_{\max}=\text{general matrix 最大长度放大倍数}}
\]

若矩阵满秩且不存在零奇异值，则最小奇异值描述最弱输入方向上的长度缩放。

这修正了 Day11 曾出现的错误理解：

> general matrix 的最大拉伸不能直接由最大 eigenvalue 判断。

---

## 6. Rank 与 Singular Value

如果：

\[
\Sigma=\operatorname{diag}(8,3,0)
\]

则第三个奇异方向被完全压成 0：

\[
Av_3=0
\]

这与 Day9 的 null space 直接对应。

因此：

\[
\boxed{\operatorname{rank}(A)=\text{非零 singular values 的数量}}
\]

几何/信息意义：

- `σ_i > 0`：该方向仍保留信息；
- `σ_i = 0`：该方向的信息完全丢失；
- `σ_i ≈ 0`：理论上未必 rank loss，但工程上该方向信息极弱，接近退化。

---

## 7. Conditioning

对可逆方阵，常用 2-norm condition number：

\[
\boxed{\kappa(A)=\frac{\sigma_{\max}}{\sigma_{\min}}}
\]

若：

\[
\sigma_{\max}=10,\qquad\sigma_{\min}=0.001
\]

则：

\[
\kappa=10000
\]

含义不是“噪声很小”，而是：

> 不同方向的信息强弱差异过大，逆问题对弱方向的 measurement noise 非常敏感。

---

## 8. 小奇异值为什么放大噪声

考虑某个弱奇异方向，标量化写成：

\[
b_w=\sigma x_w
\]

其中：

- `x_w ∈ R`：该弱奇异方向上的状态分量；
- `b_w ∈ R`：对应 measurement 分量；
- `σ ∈ R_{>0}`：该方向 singular value。

反解：

\[
x_w=\frac{b_w}{\sigma}
\]

若 measurement noise 为：

\[
\Delta b_w
\]

则状态误差近似：

\[
\boxed{\Delta x_w=\frac{\Delta b_w}{\sigma}}
\]

例如：

\[
\sigma=0.01,\qquad\Delta b=0.002
\]

则：

\[
\Delta x=0.2
\]

### 今日关键纠错

最初曾把这个过程理解成：

> 弱方向的误差会串到其他方向并被放大。

这是错误的。

在 SVD 的奇异方向坐标系里，各方向已经解耦；正确理解是：

\[
\boxed{
\text{弱奇异方向自己的 measurement noise}
\rightarrow
\text{反解时该弱奇异方向自己的 state error 被放大}
}
\]

此项经过定向复测后 PASS，但需要在后续 SLAM / LS / Jacobian 场景再次 review。

---

## 9. Invertibility 与 Conditioning 不是一回事

若方阵：

\[
\sigma_1=5,\qquad\sigma_2=10^{-6}
\]

因为：

\[
\sigma_{\min}>0
\]

所以数学上仍可逆。

但：

\[
\kappa=5\times10^6
\]

说明数值上极度 ill-conditioned。

因此：

\[
\boxed{\text{Invertibility：有没有完全丢失的方向}}
\]

\[
\boxed{\text{Conditioning：反解到底稳不稳}}
\]

“能求出一个 `x`”不等价于“这个 `x` 可靠”。

## 10. Pseudoinverse

普通 inverse 只适用于满足条件的方阵，但机器人问题经常是：

\[
Ax\approx b
\]

例如很多 measurement 估计少量 state parameters。

SVD：

\[
A=U\Sigma V^T
\]

可以构造 pseudoinverse：

\[
A^+=V\Sigma^+U^T
\]

其中 `Σ^+` 对可信的非零 singular values 做倒数。

本日只要求 L2 直觉：

> pseudoinverse 把各信息方向拆开，有信息的方向反解；完全没有信息的方向不能硬除以 0；在 overdetermined 系统中可得到 least-squares 意义的解。

复杂数值算法不在本日范围。

## 11. SLAM / ICP 退化映射

理想无限平墙的 point-to-plane residual 主要反映点沿墙面法向的距离误差。

### 垂直墙移动

法向距离明显变化，measurement 对该运动敏感：

\[
\sigma_{normal}\ \text{较大}
\]

### 沿墙平移

法向距离几乎不变，measurement 对该运动不敏感：

\[
\sigma_{parallel}\approx0
\]

因此沿墙方向约束弱，系统接近几何退化。

关键理解：

> 不是“算法突然坏了”，而是环境本身没有给这个运动方向足够的信息。

增加垂直墙运动并不能自动补出沿墙信息；需要其他几何结构、其他 sensor 或其他约束。

## 12. 与 Jacobian / Hessian 的桥梁

后续 least squares 中会出现 Jacobian：

\[
J
\]

若：

\[
J=U\Sigma V^T
\]

则：

\[
J^TJ
\]

的 eigenvalues 与：

\[
\sigma_i^2
\]

对应。

因此后续会反复看到以下几种说法描述同类问题：

- `J` 有很小 singular value；
- `J^T J` 有很小 eigenvalue；
- Hessian 某方向 curvature 很小；
- 某状态方向约束弱；
- optimization / SLAM 接近 degeneracy；
- system ill-conditioned。

本日建立桥梁，严格优化推导留到 M08 / M10。

## 15. Day12 核心结论

\[
\boxed{Av_i=\sigma_i u_i}
\]

\[
\boxed{\operatorname{rank}(A)=\#\{\sigma_i>0\}}
\]

\[
\boxed{\kappa(A)=\frac{\sigma_{\max}}{\sigma_{\min}}}
\]

以及最重要的工程直觉：

> **小 singular value = 某个方向 measurement 对 state 不敏感；反解时，该方向自己的 measurement noise 会被放大。**

这条结论后续会直接进入 calibration、least squares、ICP、SLAM degeneracy、Jacobian / Hessian 与 observability 的学习。
