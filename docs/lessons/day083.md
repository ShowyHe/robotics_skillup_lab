## 核心问题

机器人跟踪目标时，为什么不总是立刻给最大角速度、最快地消除偏差？因为纠偏有成本：执行器幅值、能量、温升、动作平顺性、噪声放大与稳定裕度。LQR 提供一种在线性模型上，通过二次型代价系统设计反馈增益的方法。

## Part A — Foundation（基础层）

### 1. 最优控制（Optimal Control）的对象

普通反馈规则如 \(u=-Kx\) 已经规定了控制形式。**最优控制**先设定目标函数与模型，再寻找使代价最小的控制策略；不意味着能在所有现实条件下达到绝对最优。

四个基本对象：动力学、状态、输入、代价。本文采用离散时间 LTI、时钟同步、确定性模型、完整状态可用的基础问题。现实的扰动、噪声和约束将单独讨论。

### 2. 离散线性动力学及维度

\[
\boxed{x_{k+1}=Ax_k+Bu_k}
\]

- \(x_k\in\mathbb R^n\)：第 k 个采样时刻状态。
- \(u_k\in\mathbb R^m\)：第 k 步控制输入。
- \(A\in\mathbb R^{n\times n}\)，\(B\in\mathbb R^{n\times m}\)。
- \(\Delta t>0\) 单位为秒；A、B 已针对指定 \(\Delta t\) 建模/离散化，改采样时间不能默认矩阵不变。

状态可以由位置、速度、航向等组成，但需统一声明对应坐标系、单位和动力学近似范围。LQR 不会自动从现网 `cmd_vel` 推出真实执行器动力学。

### 3. 调节（Regulation）的目标

先研究**原点调节**：希望状态最终趋近 \(x^\star=0\)。若实际目标是非零平衡状态，先使用偏差状态 \(e=x-x^\star\)，再在偏差模型上设计反馈。

只有说明“目标是谁、偏差怎么定义”，代价中的 \(x^TQx\) 才有明确意义。

### 4. 什么是二次型（Quadratic Form）？

对状态向量 \(x=[x_1,\ldots,x_n]^T\)，二次型为：

\[
\boxed{x^TQx}
\]

若 \(Q=\operatorname{diag}(q_1,\ldots,q_n)\)，则：

\[
x^TQx=\sum_{i=1}^{n}q_ix_i^2
\]

例如两个状态的偏差 \(e=[e_p,e_v]^T\)，\(\ Q=\operatorname{diag}(4,1)\) 时：

\[
e^TQe=4e_p^2+e_v^2
\]

位置偏差对应的权重更大。数字 4 和 1 仅是示例；如果两个状态单位不同，单看数值大小不足以判断物理优先级，还需要考虑尺度/归一化。

### 5. LQR 的阶段代价（Stage Cost）

定义：

\[
\boxed{\ell(x_k,u_k)=x_k^TQx_k+u_k^TRu_k}
\]

其中 \(Q\in\mathbb R^{n\times n}\) 通常取对称半正定（\(Q\succeq0\)），\(R\in\mathbb R^{m\times m}\) 取对称正定（\(R\succ0\)）。

- \(x^TQx\)：状态偏离目标的代价。
- \(u^TRu\)：使用控制输入的代价。
- 两项都非负；R 正定保证对非零输入产生正的二次惩罚。

LQR 的代价可以乘公共正常数而不改变最优控制；真正影响折中的是相对权重及系统模型。

### 6. Q 的物理意义

Q 确定**哪些状态偏差更不愿意容忍**。

例如简化的航向控制状态：

\[
e=\begin{bmatrix}e_\theta\\e_\omega\end{bmatrix}
\]

其中 \(e_\theta=\theta-\theta_{\rm ref}\) 的单位为 rad，\(e_\omega=\omega-\omega_{\rm ref}\) 的单位为 rad/s；角度的相减必须先使用一致的坐标系/角度约定，必要时对角度差规范化到规定区间。

\[
Q=\begin{bmatrix}q_\theta&0\\0&q_\omega\end{bmatrix}
\]

提高 \(q_\theta\) 相对值，意味着目标函数更重视航向偏差；提高 \(q_\omega\)，意味着更重视角速度偏差。**不能脱离动态耦合、归一化和输入限制，就宣称增大 Q 必然让某个实际指标单调改善。**

### 7. R 的物理意义

R 决定**控制输入使用多大要付出多少代价**。

若控制输入是角加速度 \(\alpha\)（rad/s²），可取标量 \(u=\alpha,\ R=[r]\)，则输入项为 \(r\alpha^2\)。更高的 r 往往倾向更小输入、较温和的动作，但纠偏可能更慢。

注意：惩罚输入幅值 \(u^2\) 与惩罚输入变化率 \((u_k-u_{k-1})^2\) 是不同设计；基本 LQR 不自动包含“相邻指令必须平滑”的代价。

### 8. 单位与权重归一化

如果状态含米、米/秒、弧度，\(x^TQx\) 不应该在无单位意识下随意加权。Q 和 R 的系数需使各代价可比较（可用参考量归一化，使比值无量纲）；例子：

\[
\ell=\left(\frac{e_p}{p_{\rm scale}}\right)^2+
4\left(\frac{e_\theta}{\theta_{\rm scale}}\right)^2+
2\left(\frac{u}{u_{\rm scale}}\right)^2
\]

其中 \(p_{\rm scale}\) 单位 m、\(\theta_{\rm scale}\) 单位 rad、\(u_{\rm scale}\) 与所选输入相同。权重数值必须结合具体目标与状态/控制尺度解释。

## Part B — Core Theory（核心理论层）

### 9. 有限时域（Finite Horizon）LQR 目标

设预测长度 \(N\) 步、终端状态 \(x_N\)。典型目标：

\[
\boxed{
J=\sum_{k=0}^{N-1}
(x_k^TQx_k+u_k^TRu_k)
+x_N^TQ_fx_N
}
\]

满足 \(x_{k+1}=Ax_k+Bu_k\)，初始状态 \(x_0\) 已知。\(Q_f\succeq0\) 是终端状态权重。

- \(\sum\)：在每个预测步付出的代价。
- \(x_N^TQ_fx_N\)：预测结束时仍有偏差所付的代价。
- \(N\Delta t\)：对应预测时间长度（假定等间隔采样）。
- 在**经典无约束 LQR**中，不设置硬的状态或输入不等式约束；这与后续 MPC 的重要区别之一。

### 10. 为什么不是只最小化误差？

只最小化状态偏差可能鼓励非常大的输入；只最小化输入则可能什么都不做。

LQR 两项一起衡量：在给定模型、Q、R、时域假设下，为获得更小的长期误差，是否值得使用更大的控制量。它是**权衡**，不是“误差最小就一定最优”。

### 11. 完整手算：一维 LQR 怎样选输入？（Hard Gate）

取一个清楚的教学特例（单步、无约束）：

\[
x_1=x_0+u_0,\qquad
J=q\,x_1^2+r\,u_0^2,\qquad q>0,\ r>0
\]

状态 \(x\)、输入 \(u\) 此处为同一尺度下的无量纲标量；等式可视为已吸收采样周期的归一化模型。已知 \(x_0\)，选择 \(u_0\)：

\[
J(u_0)=q(x_0+u_0)^2+ru_0^2
\]

求导：

\[
\frac{dJ}{du_0}=2q(x_0+u_0)+2ru_0
\]

令导数为零：

\[
(q+r)u_0=-qx_0
\]

得到：

\[
\boxed{u_0^\star=-\frac{q}{q+r}\,x_0}
\]

这已经是线性状态反馈 \(u=-Kx\)，其中：

\[
\boxed{K=\frac{q}{q+r}}
\]

二阶导 \(2(q+r)>0\)，所以得到唯一最小值。这个单步例子是为了理解权重如何决定反馈，不是无限时域 LQR 的完整求解公式。

### 12. Q/R 数值变化，控制行为如何变化？

在上一道**相同模型**中令 \(x_0=2\)。

- \(q=4,r=1\)：\(K=4/5=0.8\)，\(u_0^\star=-1.6\)。
- \(q=1,r=4\)：\(K=1/5=0.2\)，\(u_0^\star=-0.4\)。

第一组更重视状态偏差，采取更大的修正输入；第二组更重视控制代价，选择更小的输入。

这是从明确的目标函数推导出来的结论，**不是**“所有机器人上调大 Q 就一定不振荡、调大 R 就一定安全”的一般规律。

### 13. 为什么最优策略能写成 \(u=-Kx\)？

从上一例可见，二次型目标 + 线性动力学的优化结果，在无约束基础情形下可以得到与状态成比例的最优反馈。

对一般多维 LQR，最优反馈形式：

\[
\boxed{u_k^\star=-K_kx_k}
\]

有限时域的 K 通常随时间步变化；对满足合适条件的无限时域定常问题，K 可收敛为常数。控制器获得状态后才执行反馈；若状态不可直接测量，需另行考虑估计链路。

### 14. 有限时域与无限时域（Infinite Horizon）

**有限时域**：只优化 N 步范围，通常带终端代价 \(x_N^TQ_fx_N\)。K 可以因距离终点的步数不同而变化。

**无限时域**：

\[
\boxed{J_\infty=\sum_{k=0}^{\infty}
(x_k^TQx_k+u_k^TRu_k)}
\]

对可满足相应稳定性/检测性条件的离散 LTI 无约束问题，可以找到稳定的定常最优反馈 \(u=-Kx\)。

不能仅因为把 N 写成无限大就断言最优解一定存在且闭环稳定：存在性还要看模型与权重条件。

### 15. Riccati 方程的概念（L2–L3）

Riccati 不是另外一种传感器或控制器，而是计算**未来代价与当前状态之间关系**的数学工具。

对二次型最优代价，常写：

\[
\boxed{V(x)=x^TPx}
\]

其中 P 概括：如果从状态 x 出发、之后都按最优控制动作执行，未来总共需要付多少代价。有限时域中有 \(P_k\) 从终点递推回起点；无限时域稳态对应代数 Riccati 方程。

理解：P 与 Q 不相同；Q 惩罚**当前**状态偏差，P 还包含系统动态和未来的最优控制代价。

### 16. 离散代数 Riccati 方程（DARE）长什么样？

对本日的无交叉项、无约束离散 LQR（并在适当条件下）：

\[
\boxed{
P=Q+A^TPA-A^TPB(R+B^TPB)^{-1}B^TPA
}
\]

\[
\boxed{K=(R+B^TPB)^{-1}B^TPA}
\]

维度：\(P,Q\in\mathbb R^{n\times n}\)，\(R\in\mathbb R^{m\times m}\)，\(K\in\mathbb R^{m\times n}\)。

**本日要求**：识别其输入 A/B/Q/R、输出 P/K 和物理目的；不要求手工求解一般矩阵 Riccati，也不进行严格推导。数值软件求解还应检查返回解对应的闭环稳定性和矩阵条件。

### 17. Riccati 与闭环稳定性如何连接？

把最优反馈代回模型：

\[
x_{k+1}=(A-BK)x_k
\]

对离散 LTI，闭环全部特征值满足 \(|\lambda_i(A-BK)|<1\)，才能断言原点指数稳定。

**Q/R 设计的代价最优性不应被误读成任何设置都必然稳定**。实际可稳定性、可检测性、R 正定等条件关系到稳定解能否成立；如果不可控的不稳定模态无法通过反馈影响，不能仅靠调 Q/R 把它变成稳定。

### 18. Reference Tracking（参考跟踪）与 Error State（误差状态）

原点调节 \(u=-Kx\) 不等于跟踪任意非零参考。

对参考平衡点 \((x^\star,u^\star)\) 满足：

\[
x^\star=Ax^\star+Bu^\star
\]

定义 \(e_k=x_k-x^\star\)、\(\delta u_k=u_k-u^\star\)，得到：

\[
e_{k+1}=Ae_k+B\delta u_k
\]

因此可在偏差上用：

\[
\boxed{u_k=u^\star-K(x_k-x^\star)}
\]

**对于运动轨迹** \(x_k^{\rm ref}\) 与 \(u_k^{\rm ref}\)，若二者满足相应离散动力学：

\[
x_{k+1}^{\rm ref}=Ax_k^{\rm ref}+Bu_k^{\rm ref}
\]

同样得到：

\[
\boxed{u_k=u_k^{\rm ref}-K(x_k-x_k^{\rm ref})}
\]

这展示了**参考前馈 + 状态误差反馈**。若参考不满足所用模型，或存在扰动/模型误差，偏差动力学中还会出现非零残差，不能直接假设完美跟踪。

### 19. LQR 与 PID 有什么差别？

| 维度 | PID（Day80 复用） | LQR（今日新增） |
|---|---|---|
| 起点 | 给定误差，定义 P/I/D 反馈 | 给定状态模型与二次型代价 |
| 输入依据 | 误差、误差积分、误差变化率 | 状态（或偏差状态） |
| 增益来源 | 经验/规则/调参等 | 在所选模型和 Q/R 下求得最优 K |
| 多状态耦合 | 一般需专门设计结构 | 在 A、B、Q、R 中系统体现 |
| 稳态误差 | I 项可帮助处理某些持续扰动 | 基本 LQR 不自带积分消除扰动能力 |
| 硬约束 | 都不天然保证严格满足 | 经典无约束 LQR 不天然处理硬约束 |

不是“LQR 必然比 PID 好”，而是模型、系统结构和设计目标不同。

## Part C — Advanced / Owner（工程层）

### 20. 机器人轨迹跟踪场景

教学示例：二维状态 \(e=[e_\theta,e_\omega]^T\)，控制输入 \(u=\alpha\)（角加速度），采样步长 \(\Delta t\)：

\[
e_{k+1}=
\begin{bmatrix}1&\Delta t\\0&1\end{bmatrix}e_k+
\begin{bmatrix}\tfrac12\Delta t^2\\\Delta t\end{bmatrix}u_k
\]

这里采用恒角加速度、无其他扰动、参考角加速度已作为前馈扣除的简化模型；\(e_\theta\) 单位 rad，\(e_\omega\) 单位 rad/s，\(u\) 单位 rad/s²。

LQR 通过选择 Q/R 平衡航向误差、角速度误差和角加速度使用代价。这仅示意建模方法：实际机器狗的 MPPI 输出可能是目标角速度，而非上述角加速度；必须根据实际输入语义、底盘响应和采样时间重建 B 后才能使用。

### 21. 机械臂 / 平衡控制映射

对关节跟踪，可选择位置误差 \(e_q\)（rad）、关节速度误差 \(e_{\dot q}\)（rad/s）为状态，把力矩或其局部线性化输入作为控制量；运动耦合由 A、B 描述。

对近似平衡点附近的倒立装置/姿态稳定问题，同样可以定义姿态偏差、角速度偏差和输入。**平衡点附近局部线性控制**不能直接保证大角度翻转等远离工作点的行为；这属于模型适用范围问题。

### 22. 经典 LQR 为什么不天然处理硬约束？

基本 LQR 数学问题允许所有 \(u_k\in\mathbb R^m\)（在无约束设定下），因此计算出的命令可能超过执行器能力。

例如计算结果 \(\omega_{\rm cmd}=1.2\,\mathrm{rad/s}\)，而实际平台允许上限 \(0.6\,\mathrm{rad/s}\)：执行端限幅后真实控制变成 \(0.6\)，不再等同于用于推导最优反馈的无约束输入。

简单裁剪命令可以满足这个瞬时幅值约束，却**不能**据此宣称原优化问题仍保持最优，也不能保证所有未来状态约束都满足。如何将硬约束明确进入在线优化，是 Day84 MPC 的职责。

### 23. Q/R 调大造成摆动，究竟能下什么结论？

若真实机器人在改 Q/R 后出现摆头，只能确认参数修改与现象发生的时间关系；不能单凭它断言因果关系或“模型特征值不稳定”。

最小工程核对顺序：记录参考、LQR 输出与执行后命令；比较角速度/角度反馈的时间戳与实测动态；核对模型 A/B 与实际执行器输入定义、采样周期、限幅；再用一致的局部闭环模型检查 \(A-BK\) 的特征值。

如果控制器并非 LQR，而是 MPPI，也不能把 LQR 课堂结论直接当作现有 MPPI 算法实现的事实；只能借用“模型、代价、执行器、反馈”的责任划分。

### 24. 代码实现 / Debug 的最小检查表（L4）

读一个离散 LQR 实现时，先检查：

1. A/B 的维度、\(\Delta t\) 与物理输入类型一致吗？
2. Q/R 是否对称，Q 是否半正定、R 是否正定？权重是否考虑不同状态单位与尺度？
3. 控制目标是原点调节还是参考轨迹跟踪？有没有参考前馈？
4. Riccati 求解器返回的 P、K 是否有限且维度正确？
5. \(A-BK\) 的特征值是否满足预期离散稳定性？
6. 输出是否被限幅、延迟，真实执行器能否跟随？
7. 是否把估计状态误认为真实状态，或把输出命令误认为执行输入？

此清单是设计/验证原则，不声称已检查任何公司源码。

### 25. 今日 Hard Gate 与易错边界

- **Hard Gate：** 看懂 \(J=\sum(x^TQx+u^TRu)+x_N^TQ_fx_N\) 并能解释所有项；能在给定一维例子中通过求导求出 \(K=q/(q+r)\)。
- **Hard Gate：** 在**同一模型、同一尺度**下解释 Q 与 R 相对增减对最优输入的作用，不把趋势外推成无条件结论。
- **Hard Gate：** 明确 \(u=-Kx\) 的原点调节与 \(u=u_{\rm ref}-K(x-x_{\rm ref})\) 的跟踪区别。
- **边界：** Riccati L2–L3，理解 P/K/DARE，不做严格证明；经典 LQR 不天然处理硬约束，也不保证真实系统无超调或无误差。
- **毕业关联：** Optimal Control、LQR、Quadratic Cost；Day84 将以此连接 Horizon / Constraint / Receding Horizon，不提前讲 MPC 求解器细节。
