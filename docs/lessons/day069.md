## Mastered

- Planner Server responsibility: generate path, not control velocity.
- Controller Server responsibility: follow path and output motion commands.
- BT Navigator responsibility: manage navigation behavior flow, recovery and retry logic.
- Sequence and Fallback behavior tree semantics.
- Recovery is a behavior category including Spin, Clear Costmap and BackUp.
- Difference between planner failure and controller failure.
- Path validity checking before replanning.
- Replanning should consider environment persistence and switching cost.
- Path switching requires benefit/cost evaluation.
- Hysteresis prevents path oscillation.
- Cooldown prevents repeated switching.
