# M02 · Day9 — 基、坐标、线性变换、秩与零空间

## 今日目标
真正理解同一个物理向量在不同坐标系下为什么数字不同；理解矩阵如何表示线性变换；建立对秩、线性无关、零空间、信息丢失和可逆性的几何直觉。

## 1. 向量本身与坐标不是一回事
同一个几何向量 v，在不同基下可以有不同坐标。若 B、C 分别为两组基矩阵，则

v = B[v]_B = C[v]_C

不变的是物理/几何向量 v；改变的是所采用的基以及对应的坐标系数。

机器人中 position、velocity、normal、camera ray 等量都必须连同 frame 一起理解。

## 2. 基与坐标
二维标准基：

e1 = [1,0]^T,  e2 = [0,1]^T

若 v = 2e1 + 3e2，则 [2,3]^T 是 v 在该基下的坐标。

基：描述空间的一组相互独立的基本方向。
坐标：同一个向量在这些基向量上的线性组合系数。

## 3. 换基
若新基为 b1、b2，组成基矩阵

B = [b1  b2]

且向量在该基下坐标为 c = [c1,c2]^T，则

v = Bc = c1 b1 + c2 b2

换基后，真实向量 v 不变；基和坐标同时改变，以保证线性组合仍表示同一个 v。

## 4. y = Ax 的统一意义
最一般地：A 是一个线性变换，x 是输入，y 是输出：

x --A--> y

坐标变换只是线性变换的一种用途。A 还可能表示选择、缩放、旋转、剪切、投影、降维、状态提取、传感器观测、特征混合等。

线性变换满足：

T(ax + by) = aT(x) + bT(y)

## 5. 如何读一个矩阵
看到 y = Ax 时固定做：
1. x 是什么物理量；
2. y 是什么物理量；
3. 看 A 的维度，判断 R^n -> R^m；
4. 看 A 的列：输入空间各个基方向经过 A 后去了哪里；
5. 看 A 的行：每个输出分量由哪些输入分量线性组合得到；
6. 判断是否存在相关列、降秩和信息丢失。

## 6. 矩阵列的几何意义
若 A = [a1,a2,...,an]，则

Aei = ai

所以 A 的第 i 列，就是第 i 个标准基向量经过 A 后的位置。

任意 x = sum xi ei，因此

Ax = sum xi Aei = sum xi ai

这就是矩阵乘向量的几何意义。

## 7. 常见线性变换
### 选择
例如 x=[px,py,vx,vy]^T，只选择位置：

A = [[1,0,0,0],[0,1,0,0]]

本质：需要的变量系数置 1，其余置 0。

### 缩放
A = diag(2,3) 表示 x 方向放大 2 倍、y 方向放大 3 倍。

### 旋转
二维旋转矩阵

R(theta) = [[cos(theta),-sin(theta)],[sin(theta),cos(theta)]]

它的两列分别是标准基 e1、e2 旋转 theta 后的位置，所以能使任意向量按同样规则旋转。

### 剪切
A = [[1,1],[0,1]]，其中 e1 保持不变，e2 被拉到 [1,1]^T，整个网格发生剪切。

### 投影
A = [[1,0],[0,0]]，保留 x 方向，完全消掉 y 方向；二维平面被压到 x 轴。

### 降维
例如 2x3 矩阵把 R^3 映射到 R^2。若某些方向不再出现在输出中，就发生信息丢失。

### 混合变量
A = [[1,1],[1,-1]] 时，输出为 x1+x2 与 x1-x2，本质是重新组合输入变量。

## 8. 坐标变换与“把对象真的旋转”要区分
同一个旋转矩阵在不同语境下可能表示：
- Active：几何向量本身被旋转；
- Passive：几何向量不动，只更换描述它的坐标系。

机器人 TF、相机外参、IMU 姿态中必须明确“哪个 frame 到哪个 frame”。

## 9. 线性无关
两个二维非零向量若互不成倍数，则线性无关，因为它们能提供两个不同方向。

例如 a2 = 2a1，则已有 a1 后，a2 没提供新的方向，二者只能张成一条直线，因此线性相关。

更一般地，一组向量 a1,...,an 线性无关，意味着只有全部系数都为 0 才能满足

c1 a1 + ... + cn an = 0

若存在不全为 0 的系数组合得到 0，则线性相关。

三维中“两个向量不是倍数”并不足以保证三个向量独立；若 a3 = a1 + a2，则三者仍只张成一个平面。

## 10. 秩
秩可直观理解为：

> 线性变换之后还能产生多少个相互独立的输出方向。

例如

A = [[1,2],[2,4]]

第二列是第一列的 2 倍，所以所有输出 Ax 最终都落在 span([1,2]^T) 这一条线上，故 rank(A)=1。

二维输入经过 rank=1 的变换后，只剩 1 个独立输出方向。

## 11. 零空间
零空间定义：

N(A) = {x | Ax = 0}

其几何意义是：哪些非零输入方向经过 A 后被完全消掉。

例如

A = [[1,2],[2,4]]

d = [-2,1]^T

有 Ad=0，因此 d 属于 A 的零空间。并且任意 lambda*d 也满足 A(lambda d)=0，所以零空间不是一个点，而是一个方向/子空间。

## 12. 行空间与零空间
Ax 的每一个输出分量，本质上都是 A 的某一行与 x 的内积。因此：

N(A) 与 A 的行空间正交。

本例 A 是对称矩阵，行空间和列空间恰好重合，均由 [1,2]^T 张成，所以 [-2,1]^T 也与该张成方向垂直。这个“垂直于列空间”的直觉只在这种特殊情形下成立，不能泛化到任意矩阵。

## 13. 零空间的物理意义
若 d != 0 且 Ad=0，则对任意输入 x：

A(x+d)=Ax+Ad=Ax

也就是系统沿 d 方向改变输入时，输出完全不变。

这可以理解为：
- 传感器看不见这个方向；
- 这个输入方向对输出没有贡献；
- 某些输入组合的效果相互抵消；
- 这个方向的信息没有被输出保留下来。

本例中第二列 a2=2a1，因此输入第一维减少 2、第二维增加 1 时，两个贡献正好抵消，输出完全不变。

## 14. 秩、零空间和信息丢失
以二维输入为例：
- rank=2：两个独立方向都保留；
- rank=1：只剩一个独立输出方向，至少一个输入方向被完全消掉；
- rank=0：所有方向都被压到 0。

因此：

秩 = 被保留下来的独立输出方向数。
零空间 = 被完全消掉的输入方向集合。

若方阵 rank<n，则存在非零零空间，不同输入可能产生同一输出，无法唯一恢复输入，因此矩阵不可逆。

## 15. 机器人观测中的零空间
状态

x=[px,py,vx,vy]^T

若传感器只观测位置：

z=Hx,
H=[[1,0,0,0],[0,1,0,0]]

则 d=[0,0,1,0]^T 或 [0,0,0,1]^T 都满足 Hd=0。

物理意义：单看这一时刻的位置观测，速度方向的变化不会直接改变传感器输出，因此这些方向对该观测方程不可见。

## 今日统一总结
1. 同一物理向量可在不同基下有不同坐标；
2. 矩阵是线性变换的表示；
3. 看列：基方向被送到哪里；
4. 看行：输出每一维如何由输入组合；
5. 线性无关 = 提供新的独立方向；
6. 秩 = 保留下来的独立输出方向数；
7. 零空间 = 被完全消掉的输入方向；
8. 非零 d 满足 Ad=0 时，系统沿 d 方向改变输入，输出完全不变；
9. 正常完整坐标变换必须可逆，不应有非零零空间；
10. 坐标变换只是线性变换的一种用途，不要把所有 Ax 都理解成“换坐标系”。
