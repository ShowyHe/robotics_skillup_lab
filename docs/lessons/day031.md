## 1. 今日主线

CNN = Convolutional Neural Network（卷积神经网络）。

核心链：

\[
Image
\rightarrow
Convolution
\rightarrow
Feature\ Map
\rightarrow
Higher\ Level\ Feature
\rightarrow
Task\ Head
\]

CNN 适合图像的两个核心原因：

\[
\boxed{\text{Locality（局部性）}}
\]

\[
\boxed{\text{Parameter Sharing（参数共享）}}
\]

---

## 2. Image Tensor（图像张量）

单张 RGB 图像通常表示为：

\[
C\times H\times W
\]

加入 Batch 后：

\[
N\times C\times H\times W
\]

例如：

\[
8\times3\times640\times640
\]

分别表示：
- Batch Size = 8
- Channel = 3
- Height = 640
- Width = 640

---

## 3. 为什么不用巨大 Fully Connected Layer（全连接层）

高分辨率图像直接展平后参数量极大，同时忽略了图像强烈的局部空间结构。

CNN 利用：
- Locality：局部 Pattern（模式）通常由邻域 Pixel（像素）关系决定
- Parameter Sharing：同一 Kernel（卷积核）在不同位置复用同一组 Weight（权重）

因此参数量更少，也更符合视觉任务结构。

---

## 4. Convolution（卷积）

卷积可以理解为 Kernel 在局部区域滑动，对对应位置做加权组合：

\[
y=\sum_i x_iw_i+b
\]

卷积本身仍然是 Parameterized Linear Operation（参数化线性运算），通常后面接 ReLU 等 Activation Function（激活函数）形成非线性网络。

---

## 5. Kernel / Filter（卷积核 / 滤波器）

对输入：

\[
C_{in}\times H\times W
\]

卷积 Weight Tensor（权重张量）通常为：

\[
\boxed{
C_{out}\times C_{in}\times K_H\times K_W
}
\]

例如：

\[
C_{in}=3,\quad C_{out}=64,\quad K=3\times3
\]

则：

\[
\boxed{
64\times3\times3\times3
}
\]

---

## 6. Parameter Sharing（参数共享）

同一个 Kernel 会在整张图不同位置滑动，并重复使用同一组 Weight。

这使网络能够在不同位置检测相同类型的局部 Pattern。

---

## 7. Feature Map / Channel

经过卷积后，Channel 不再只是 RGB。

例如：

\[
128\times80\times80
\]

其中 128 表示：

\[
\boxed{
128个 Learned Feature Channel（学习得到的特征通道）
}
\]

不是 128 种颜色。

---

## 8. Stride（步长）

Stride 控制 Kernel 每次移动多少 Pixel。

Stride 增大通常会使：

\[
H_{out},W_{out}\downarrow
\]

从而降低 Spatial Resolution（空间分辨率）。

---

## 9. Padding（填充）

Padding 用于：
- 控制 Feature Map 尺寸
- 让 Kernel 能覆盖边缘区域

卷积输出尺寸：

\[
H_{out}
=
\left\lfloor
\frac{H+2P-K}{S}
\right\rfloor+1
\]

宽度同理。

---

## 10. 输出尺寸计算

例如：

\[
H=W=64,\quad K=3,\quad S=2,\quad P=1
\]

则：

\[
H_{out}
=
\left\lfloor
\frac{64+2-3}{2}
\right\rfloor+1
=
32
\]

因此：

\[
\boxed{
H_{out}=W_{out}=32
}
\]

---

## 11. Receptive Field（感受野）

Receptive Field 表示：

\[
\boxed{
某个 Feature 最终能够受到原始图像多大区域影响
}
\]

随着多层卷积叠加，高层 Feature 间接依赖越来越大的原图区域，因此可以利用更广的上下文。

---

## 12. Pooling / Downsampling（池化 / 下采样）

作用：
- 降低空间尺寸
- 减少计算量
- 更快扩大 Receptive Field

代价：

\[
\boxed{
空间细节会损失
}
\]

Segmentation（分割）、Depth（深度）等 Pixel-level Task（像素级任务）尤其需要注意这一点。

---

## 13. Hierarchical Features（层级特征）

CNN 可以粗略理解为逐层形成：

\[
Pixel
\rightarrow
Edge/Texture
\rightarrow
Local\ Pattern
\rightarrow
Object\ Part
\rightarrow
Semantic\ Feature
\]

这只是理解层级表示的直觉，不代表每一层有固定的人类语义。

---

## 14. Translation Equivariance（平移等变性）

由于同一个 Kernel 在不同位置复用，输入 Pattern 平移时，Feature Response（特征响应）通常也会随位置平移。

这是 CNN 的重要视觉 Inductive Bias（归纳偏置）之一。

---

## 15. Backbone / Task Head

典型视觉结构：

\[
Image
\rightarrow
Backbone
\rightarrow
Feature
\rightarrow
Task\ Head
\]

Backbone（骨干网络）负责提取 Feature。

不同 Task Head（任务头）负责不同任务：

- Classification Head → Class
- Detection Head → Bounding Box + Class
- Segmentation Head → Pixel Class
- Depth Head → Depth
