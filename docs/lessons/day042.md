## 2. Probability vs Likelihood

同一个表达式：

p(D|theta)

当 theta 固定、D 变化时：
- 看的是数据在给定参数下如何分布；
- 可视作 Probability Distribution（概率分布）。

当 D 已经固定、theta 变化时：

L(theta)=p(D|theta)

称为 Likelihood（似然）。

核心：
- Probability：固定参数，看数据怎么分布
- Likelihood：固定已观测数据，比较不同候选参数

## 3. Likelihood 不是参数本身的概率

Likelihood：

L(theta)=p(D|theta)

表示：
- 当前候选参数 theta 对已经观测到的数据 D 的解释能力；
- 不等于 p(theta|D)。

因此 Likelihood 对 theta 不要求归一化为 1。

## 4. Product Likelihood（乘积似然）

若给定 theta 后，各测量条件独立：

p(D|theta)=prod_i p(z_i|theta)

多个观测共同约束同一个参数，要求参数整体上最好解释全部数据。

## 5. MLE（Maximum Likelihood Estimation，最大似然估计）

定义：

theta_hat_MLE = argmax_theta p(D|theta)

含义：
- 找出最能解释当前已经观测到的数据 D 的参数 / 状态 theta。

argmax 返回的是让目标函数达到最大的参数，而不是最大函数值本身。

## 6. Log Likelihood（对数似然）

大量小概率直接连乘容易造成 Numerical Underflow（数值下溢）。

取对数：

log L(theta)
= log prod_i p(z_i|theta)
= sum_i log p(z_i|theta)

于是：
- 连乘变成求和；
- 数值更稳定；
- 更利于求导和优化。

因为 log 是严格单调递增函数：

argmax L(theta) = argmax log L(theta)

这里不是因为 theta 增大，而是因为 log 保持函数值的大小排序。

## 7. Negative Log Likelihood（NLL，负对数似然）

优化通常写作 Minimize（最小化）。

因此：

argmax log L(theta)

等价于：

argmin -log L(theta)

其中：

-log L(theta)

称为 Negative Log Likelihood（负对数似然）。

## 8. MAP（Maximum A Posteriori，最大后验估计）

Bayes：

p(theta|D)
=
p(D|theta)p(theta)/p(D)

由于 D 已固定，p(D) 与 theta 无关。

因此：

theta_hat_MAP
=
argmax_theta p(theta|D)

等价于：

theta_hat_MAP
=
argmax_theta p(D|theta)p(theta)

所以：

- MLE：只看 Likelihood（似然）
- MAP：Likelihood（似然） + Prior（先验）

## 9. Prior（先验）的准确含义

Prior：

p(theta)

表示：

在看到当前这批数据 D 之前，根据已有信息，对当前参数 / 状态 theta 的可信程度。

序贯状态估计里，它常由过去的数据和上一轮估计形成，但它不是“过去某个事件发生过多少次的概率”。

更准确的表述：

Prior = 过去信息形成的、对当前状态的判断。

## 10. Gaussian Noise → Squared Residual

测量模型：

z_i = h_i(theta) + epsilon_i

其中：

epsilon_i ~ N(0, sigma^2)

定义 Residual（残差）：

r_i = z_i - h_i(theta)

高斯似然：

p(z_i|theta)
propto
exp(-r_i^2/(2 sigma^2))

Residual 越大，Likelihood 越低。

## 11. Gaussian + MLE → Least Squares

多个独立高斯测量：

L(theta)=prod_i p(z_i|theta)

取 Negative Log 后，忽略与 theta 无关的常数：

-log L(theta)
propto
sum_i r_i^2/(2 sigma^2)

若各测量 sigma 相同：

theta_hat
=
argmin_theta sum_i r_i^2

这就是 Least Squares（最小二乘）。

核心链：

Gaussian Noise
→ Likelihood
→ Negative Log
→ Squared Residual
→ Least Squares

## 12. Measurement Uncertainty → Weight

若不同测量方差不同：

Cost
propto
sum_i r_i^2/sigma_i^2

因此：

sigma_i 越小
→ 认为 Measurement（测量）越可靠
→ 1/sigma_i^2 越大
→ 同样 Residual（残差）受到更重惩罚

这直接连接 Day43 Weighted Least Squares（加权最小二乘）。

## 13. Neural Network Loss Connection

很多机器学习 Loss（损失）可以从概率模型推导：

Probability Model
→ Likelihood
→ Negative Log Likelihood
→ Loss

例如分类问题中的 Cross Entropy（交叉熵）可从最大似然角度理解。

## 14. SLAM / Calibration Connection

估计问题常见结构：

Measurements
→ Sensor Model
→ Likelihood
→ Residual
→ Optimization
→ State / Parameter Estimate

概率语言：
- Maximum Likelihood / MAP

优化语言：
- Minimize Residual Cost

本质上是在描述同一个 Estimation Problem（估计问题）的不同层面。
