## 2. 核心讲义

### 2.1 雅可比：向量函数的一阶导数矩阵

设 f:R^n→R^m，输入 x=[x_1,...,x_n]^T，输出 y=[f_1(x),...,f_m(x)]^T。雅可比定义为：

```text
(J_f)_ij = ∂f_i/∂x_j
J_f ∈ R^(m×n)
```

每行对应一个输出，每列对应一个输入；每个元素是该输出对该输入的局部敏感度。它也可理解为把每个输出的梯度转置后按行排列。标量函数 C:R^n→R 的梯度是 n×1 列向量，而其行雅可比是 1×n；不能把所有雅可比都叫作代价梯度。

例：f(x,y)=[x²+y,xy]^T，输入输出均为 R²。逐项求导：

```text
J_f(x,y) = [[2x,1],[y,x]]
J_f(1,2) = [[2,1],[2,1]]
J_f(3,4) = [[6,1],[4,3]]
```

### 2.2 小变化映射与一阶泰勒

对于当前工作点 x_0 和小输入变化 Δx：

```text
Δy ≈ J_f(x_0) Δx
f(x_0+Δx) ≈ f(x_0)+J_f(x_0)Δx
```

前式预测输出变化，后式预测新的输出值。维度是 (m×1)≈(m×n)(n×1)。矩阵每行把所有输入的小变化按偏导加权求和。雅可比各列的物理单位应是对应输出单位除以对应输入单位；混合位置和角度时不能只看数值维度。

在 x_0=[1,2]^T、Δx=[0.01,0.02]^T 时：

```text
Δy_linear = [[2,1],[2,1]][0.01,0.02]^T = [0.04,0.04]^T
f(1,2)=[3,2]^T
f(1.01,2.02)=[3.0401,2.0402]^T
Δy_true=[0.0401,0.0402]^T
```

一阶结果接近但不等于真实变化，因为忽略了高阶项。

一维泰勒：f(x_0+Δx)≈f(x_0)+f'(x_0)Δx。对于 f(x)=x²、x_0=2、Δx=0.1，一阶估算 4.4，真实值 4.41；差 0.01 来自被忽略的 (Δx)²。若函数本身是仿射函数，在相同坐标表示下该一阶表达式可精确成立；非线性模型通常只在局部近似。

### 2.3 工作点与非线性判断

线性化不是永久改变原函数。雅可比通常依赖当前状态，工作点改变后要重新计算。f(x)=x² 的导数为 2x，在 x_0=2 处的近似为 4+4(x-2)，其斜率固定为4；原函数的斜率仍随 x 变化。不能将大范围变化的预测准确性视为已保证。

必须区分：梯度不为0不代表非线性，f(x)=2x 的导数恒为2；某点海森为0也不代表全局线性，f(x)=x³ 在0点二阶导为0。非零二阶导说明当前附近不可能是仿射函数；一阶近似误差还受变化范围、高阶项及原模型误差影响。线性函数与仿射函数在严格定义上不同：Ax 是线性的，Ax+b 一般是仿射的；工程中的“线性化”通常允许常数项。

### 2.4 物理例子：位置与航向到预测位置

二维平面中，输入 s=[x,θ]^T，其中 x 单位 m、θ 单位 rad；机器人从 (x,0) 朝 θ 方向移动固定距离 L=1 m。输出 p=[p_x,p_y]^T，单位 m：

```text
p_x=x+L cosθ
p_y=L sinθ
J_p=[[1,-L sinθ],[0,L cosθ]]
```

在 θ=0 时，Δx=0.1 m、Δθ=0.1 rad，一阶预测 Δp=[0.1,0.1]^T m。第一列对应位置变化，第二列对应航向变化；第二列单位为 m/rad，不能把角度变化误认为角速度。该例只说明几何局部敏感度，不代表实际底盘控制命令或完整运动学模型。

### 2.5 海森：梯度的雅可比

对于二次可微的标量函数 C:R^n→R：

```text
∇C=[∂C/∂x_1,...,∂C/∂x_n]^T ∈ R^n
(H_C)_ij=∂²C/(∂x_i∂x_j)
H_C=J_(∇C) ∈ R^(n×n)
Δ(∇C)≈H_C Δx
```

海森是梯度的一阶变化矩阵，也是原标量函数的二阶导数矩阵，描述局部曲率。它的行对应梯度分量，列对应原输入变量。n个输入产生n个梯度分量，每个分量再对n个输入求偏导，因此是n×n；不是标量，也不是只收集对角线元素的向量。若二阶混合偏导连续，海森对称。

例：C(x,y)=x²+3y²：

```text
∇C=[2x,6y]^T
H_C=[[2,0],[0,6]]
```

2和6是两个对角曲率，交叉偏导为0。对于 C=(x-2)²+4(y-1)²，海森为 diag(2,8)。海森特征向量表示主曲率方向、特征值表示该方向曲率；不要与协方差的方差特征值、二次代价矩阵的权重特征值混淆。梯度为0并不足以断言最小值；正定海森提供严格局部极小值的常用充分条件，但本日不展开二阶优化算法。

### 2.6 四条机器人主线

**EKF（扩展卡尔曼滤波）**：状态 s→预测测量 h(s)，测量雅可比 H=∂h/∂s 描述状态小变化如何影响预测测量。例 s=[x,y,θ]^T、h(s)=[x,y]^T，则 H=[[1,0,0],[0,1,0]]，是2×3。H不是测量值或协方差；完整滤波推导留给 M09。

**SLAM（同时定位与建图）**：状态→预测观测→残差 r(s)。残差雅可比 J_r=∂r/∂s，满足 Δr≈J_rΔs。若定义 r=z_observed-h(s)，且观测固定，则 J_r=-∂h/∂s；若残差定义反过来，符号也反过来。后续 ICP、非线性最小二乘和因子图使用同一本质；不在本日展开高斯—牛顿。

**机械臂逆运动学（IK）**：关节 q∈R^n→末端位置或位姿参数 p=f(q)∈R^m，Δp≈J_qΔq，J_q 为 m×n。例如4关节到3维位置是3×4。雅可比不要求先定义代价函数；完整空间/本体雅可比与 Twist 留给 M12。

**控制（Control）**：非线性离散模型 s_(k+1)=f(s_k,u_k)，在当前状态和输入附近有 Δs_(k+1)≈AΔs_k+BΔu_k，其中 A=∂f/∂s、B=∂f/∂u。二者均为雅可比；本日只建立局部模型直觉，不展开完整 MPC 或控制器实现。

统一关系：输入变化→输出变化用雅可比；输入变化→梯度变化用海森。后者是梯度函数的雅可比。不能把所有雅可比都说成代价梯度矩阵。

### 暴露的错误与处理

1. 对 f:R³→R² 初次把雅可比写成3×2，且把行列都说成输出；已纠正为输出决定行、输入决定列。
2. 把标量函数梯度写成1×4而未说明转置，并把海森维度写成1×3；已纠正列梯度4×1、海森4×4。
3. 把海森写成标量或向量 (2,8)/(2,6)，漏掉交叉偏导；已纠正为对梯度每个分量再对所有输入求导的完整矩阵。
4. 曾把非线性判断归因于梯度不为0；自行修正为梯度变化率，并进一步明确局部二阶导为0不能证明全局线性。
5. 机械臂4输入、3输出的雅可比初次写成4×3；已纠正为3×4，矩阵乘法维度必须匹配。
6. 起初将雅可比理解为所有场景的代价梯度矩阵；已纠正其适用于一般向量函数，海森才是标量梯度的雅可比。
7. EKF与SLAM的英文术语阻碍理解；补充中文名称、状态→预测测量及状态→残差的具体例子。
