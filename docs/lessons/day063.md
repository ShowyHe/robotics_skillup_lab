## 2. Foundation — Graph 基本对象

- Graph `G=(V,E)`：`V` 是节点集合，`E` 是边集合；规划中的节点是**选定的搜索状态**，不必等同于单个空间点。
- 2D Grid 节点可设为 `(x,y)`；Hybrid A* 将 heading 纳入 `(x,y,theta)`；HPA 节点可对应 Portal/Gateway。
- Edge `(u,v)` 表示允许从 `u` 向 `v` 转移；实际连接仍需检查障碍与合法性。
- Directed（有向）允许 `u→v` 不允许 `v→u`；Undirected（无向）连接双向。
- Weighted（加权）给边分配 `c(u,v)`；Unweighted（无权）在 BFS 语境通常对应各边相同权重。
- Neighbor `N(u)`：与 `u` 有直接合法连接的节点；无向图 Degree 是关联边数；有向图区分 In-degree / Out-degree。
- Walk 可重复顶点/边；Simple Path 不重复顶点；Cycle 从节点出发后又回到该节点。
- Reachability（可达）表示存在起点到目标的合法路径；Connected（无向图连通）表示任意两节点可达；否则可分 Connected Components。
- Adjacency Matrix（邻接矩阵）：通常 `O(|V|²)` 空间、单条边查询 `O(1)`。
- Adjacency List（邻接表）：通常 `O(|V|+|E|)` 空间，适合稀疏 Graph（如每格最多 4/8 邻居）。
- 4-connected Grid：`(x±1,y)`、`(x,y±1)`；8-connected 再含 `(x±1,y±1)`。斜向还需防止 Corner Cutting（穿墙角），于 Day64 细学。
- Resolution 为 `r` m/cell 时，直邻几何距离 `r` m，斜邻 `sqrt(2) r` m。

## 3. Foundation — Queue / BFS

- Queue（队列）遵循 FIFO（先进先出）。BFS（Breadth-First Search，广度优先搜索）按 Edge 数组成的层逐层访问。
- BFS 最早发现一个节点时，可记录 `visited[v]=true`、`parent[v]=u`；可防环并恢复路径。
- 所有 Edge 权重相同时，第一次发现 Goal 对应的 Path 具有**最少边数**，也就具有最小总代价。
- 边权不等时，FIFO 层数不能代表累计 Cost，普通 BFS 无法保证 Minimum Cost Path。
- BFS 复杂度：邻接表实现中，时间 `O(|V|+|E|)`，额外空间通常 `O(|V|)`。

## 4. Core — Weighted Shortest Path / Dijkstra

路径 `P=(v_0,...,v_k)` 的总代价：

```text
C(P) = sum_{i=0}^{k-1} c(v_i,v_{i+1})
P* = argmin_{P: start→goal, feasible} C(P)
```

- `c(u,v)`：从 `u` 到 `v` 的 Edge Cost；实际单位由 Cost Function 定义（可为距离、时间或经量纲一致化的加权代价）。
- `g(n)`：当前**发现的**从 Start 到节点 `n` 的最低累计代价（tentative distance），不是单条边的代价。
- 初始化：`g(start)=0`；其余 `g(n)=∞`（尚未发现有效路线）；`parent` 未定义。
- Relaxation（松弛）：若 `g(u)+c(u,v) < g(v)`，则更新 `g(v) ← g(u)+c(u,v)` 和 `parent(v) ← u`。
- Priority Queue / Min-Heap（优先队列 / 最小堆）：总是优先取出**目前累计 `g` 最小的待处理节点**；算法不锁定搜索方向。
- `visited/closed/settled` 表示最终最短代价已确定；重复插入堆时，应跳过 `visited` 或旧 `queued_cost>g(u)` 的 Stale Entry（过期项）。
- 非负权条件 `c(u,v)≥0`：在所有边权非负、队列正确执行松弛的前提下，`u` 首次以最小 `g` 正式取出时可以 finalize。
- 负权边即使没有负权环也能打破这种“第一次最小出队即最优”的保证；负权环是更严重的另一个问题。
- `parent(goal) → ... → start` 逆向回溯并反转，可恢复最终 Path。
- Goal Unreachable：队列耗尽仍无法到达 Goal；Start=Goal：总代价 0、路径只含 Start；相等代价路径允许存在多个最优解。
- 邻接表 + 二叉堆的典型复杂度 `O((|V|+|E|) log |V|)`（使用可重复入堆实现时也可按 `O((|V|+|E|)log(|V|+|E|))` 细算）；空间 `O(|V|+|E|)`，具体实现的堆条目空间还受重复入堆影响。

### 4.1 数值手推

无向非负权图：`A-B:2`，`A-C:5`，`B-D:2`，`C-D:1`。Start=A，Goal=D。

1. 初始化：`g(A)=0`、`g(B)=g(C)=g(D)=∞`。
2. 弹 A：更新 `g(B)=2,parent(B)=A`；`g(C)=5,parent(C)=A`。
3. 弹 B（2 最小）：更新 `g(D)=4,parent(D)=B`。
4. 弹 D（4 小于 C 的 5）：Goal settled，可终止；恢复 `A→B→D`，Cost=4。

**纠正的误区**：一旦弹出 B，不意味着沿 B 的某个方向一直走；每轮都重新根据队列最小 `g` 决定下一个要处理的节点。

### 4.2 搜索伪代码

```cpp
g[start] = 0;
pq.push({0, start});
while (!pq.empty()) {
    auto [candidate_g, u] = pq.pop_min();
    if (visited[u] || candidate_g > g[u]) continue;
    visited[u] = true;
    if (u == goal) break;
    for (auto [v, cost] : neighbors(u)) {
        if (visited[v]) continue;   // 成立前提：所有 cost>=0
        auto alt = g[u] + cost;
        if (alt < g[v]) {
            g[v] = alt;
            parent[v] = u;
            pq.push({alt, v});
        }
    }
}
```

以上是算法示意伪代码，不是可直接编译的 C++ 接口定义。

## 5. Advanced / Owner — Navigation 映射

- Occupancy Grid：合法 free cells 形成 Vertex，允许移动的邻接关系形成 Edge；不同机器人 Footprint/Collision 可能使同一地图的可通行 Edge 不同（详见 Day65）。
- Road Graph：交叉路口可为 Vertex、道路可为 Edge；Cost 可能是距离/时间/转弯惩罚。
- Costmap → Edge Cost → Path Cost → Path Choice；概念上可写 `c(u,v)=distance(u,v)+lambda * obstacle_term(u,v)`，但实际必须核对量纲、权重、障碍硬约束以及具体 Planner 的边代价实现。**最小 Cost 不保证几何最短。**
- HPA：大图抽象成 Cluster/Portal/Abstract Graph，仍可使用图搜索，主要优化状态空间规模；抽象误差与动态边失效留 Day68。
- A*：使用 `f(n)=g(n)+h(n)` 作为扩展优先级；`h=0` 时退化为 Dijkstra（详见 Day64）。
- 阅读 Planner 的五个问题：Node 是什么？Edge/Transition 是什么？Cost 如何计算？按什么规则扩展？Parent/Primitive Chain 如何恢复 Path？
