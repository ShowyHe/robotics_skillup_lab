## A. Foundation（1–10）

### 01. Occupancy Grid
用固定 Resolution 将连续空间分成 Cells，环境占据描述不等于有限尺寸机器人可通行性。

### 02. Free / Occupied / Unknown
Free 表示已有空闲证据；Occupied 表示占据证据；Unknown 表示缺少有效信息。**Unknown ≠ Free**；雷达无回波也可能源于遮挡/盲区/滤波/丢包，不能当作障碍已清除。

### 03. Ray Casting 的证据链
理想雷达射线：穿过的可见空间提供 Free 证据，命中处提供 Occupied 证据；未观测区域不能推断为空。噪声与时间决定证据可靠度。

### 04. Resolution
`r`（m/cell）；尺寸 `Lx×Ly` 对应 `Nx=Lx/r, Ny=Ly/r`（边界取整和 map 尺寸需按具体实现）；例如 30m×20m、r=0.05m/cell ⇒ 600×400=240000 Cells。

### 05. Cell Index ↔ World Position
轴对齐、原点 `(x0,y0)` 时：`i=floor((x−x0)/r)`、`j=floor((y−y0)/r)`，先校验边界；若地图原点带旋转，必须先变换至地图局部坐标系。栅格中心反推 `x≈x0+(i+0.5)r` 等，前提是原点定义为栅格角点且地图无旋转。

### 06. Frame / Timestamp
Footprint 常定义于 `base_link`；障碍/地图可能位于 `map`；需要相应时刻有效 TF。旧定位/旧 obstacle 数据与新地图混用，可能形成虚假的碰撞检查结果。

### 07. Occupancy vs Costmap
Occupancy 回答环境空间是否被占据；Costmap 将静态地图、动态观测、禁行与距离代价转成 Planner 使用的表示。

### 08. Nav2 Costmap 典型值
`0` FREE_SPACE；`1..252` 非致命代价；`253` INSCRIBED_INFLATED_OBSTACLE；`254` LETHAL_OBSTACLE；`255` NO_INFORMATION。255 不是“比254更硬”的障碍，处理方式取决于未知空间策略。

### 09. Robot ≠ Point
中心 Cell 空闲不等于身体可放入该位姿；同一地图上，尺寸/方向不同的机器人有不同的可行配置集合。

### 10. Circular / Polygon Footprint
圆形 Footprint 旋转不改变几何；多边形更准确表达长宽与局部形状，但必须考虑 Yaw 和运动过程。需要核对 `base_link` 参考点与实际机身/腿部有效几何。

## B. Core Theory（11–22）

### 11. Body Footprint → World Footprint
轮廓点 `p_b=(x_b,y_b)^T`、位姿 `q=(x,y,θ)`，`p_m=R(θ)p_b+[x,y]^T`；`R=[[cosθ,-sinθ],[sinθ,cosθ]]`。坐标单位 m，角度 θ 按 rad、地图 z 轴逆时针为正。多边形所有顶点及边都需要转换和检查。

### 12. Geometric Collision
`F(q)` 是世界坐标下机器人占据区域，`O` 是障碍物占据区域。`F(q)∩O=∅` 表示当前位姿无几何相交；`F(q)∩O≠∅` 表示几何碰撞。**中心点不在254，不等于 Footprint 与254不相交**。

### 13. C-space 最小桥
圆形机器人半径 `r_b` 时，可通过障碍外扩 `r_b`，把点机器人检查转为外扩障碍中的中心点检查；本质是 Configuration Space / Minkowski Sum 思路。复杂多边形含朝向时不能简单用一个固定小圆全替代。

### 14. Inscribed / Circumscribed Radius
`r_in` 是参考点到轮廓边界的最近距离；`r_out` 是到轮廓的最远距离。中心长方形 `0.8m×0.6m` ⇒ `r_in=0.3m`、`r_out=sqrt(0.4²+0.3²)=0.5m`。它们不是同一个半径。

### 15. Inflation Layer
距离障碍越近 Cost 越高。典型指数衰减区可理解为 `C(d)∝exp[-k(d-r_in)]`（`d`、`r_in` 单位 m；`k` 单位 m⁻¹），还需理解致命/内接特殊值与截断半径；具体算法及比例常数以对应版本的实现为准。

### 16. Inflation Radius ≠ Robot Radius
`inflation_radius` 是 Cost 扩散半径，`r_out` 是机器人实际 Footprint 外接半径。例 `r_inflation=0.35m<r_out=0.50m`：仅中心 Cost 低，不能证明身体无碰撞；反过来也不能声称必撞，因为精确 Footprint Check 仍可能正确排除碰撞。253 的近障风险语义也依赖参数一致性。

### 17. Center Free but Body Collision
机器人宽 0.6m，中心离平行墙 0.2m；半宽 0.3m，`0.2<0.3`，当前位姿发生几何重叠，即使中心栅格 Free。

### 18. Path Point vs Path Edge Collision
`P={q_0,...,q_N}`，各离散位姿 `F(q_i)∩O=∅`，不保证相邻姿态间 `q(t)` 安全。必须对整个运动段 Swept Volume/扫掠碰撞作连续或足够保守的离散检查；尤其路径跨障、旋转和 Hybrid A* Primitive。

### 19. Center Clearance / Body Clearance
中心到障碍距离不等于身体最短距离。理想圆机器人 `d_body=d_center-r_b`（无重叠且几何简单）；例 `0.4-0.3=0.1m`。

### 20. Narrow Passage / Safety Margin
居中直行、矩形宽 `B`、通道宽 `W`，每侧真实净空 `d=(W-B)/2`；要求余量 `m` 则 `W≥B+2m`。例 `W=0.8,B=0.62,m=0.06` ⇒ 净空 0.09m/侧、超出目标余量 0.03m/侧，满足直行条件；转弯或定位误差还需重新判断。

### 21. Unknown Planning Semantics
允许在 Unknown 上搜索，不等于 Unknown 安全。近场点在 LaserScan 生成前被过滤，可能让地图将未证明空间错误地视为 Free；优先追踪 Perception/Filter/Costmap 证据。

### 22. Costmap Layers / Filters
典型 Static / Obstacle / Voxel / Inflation Layers 以及 Keepout Filter。分清 Marker/Clearing/TF/刷新顺序与 Filter 语义。膨胀层不能凭空创造未被标记的障碍；Keepout 属于过滤机制，不能完全当作普通 Layer 等价看待。

## C. Advanced / Owner（23–28）

### 23. Marking/Clearing/Freshness
新鲜有效观测可 Marking 或 Clearing；数据过期不意味着障碍已离开。遇到断流、过期 TF、过滤误删必须审视 Unknown/Fail-safe 策略，不能无条件清除成 Free。

### 24. Costmap → Edge Cost 与硬约束
概念式 `c(u,v)=d(u,v)+λφ(C(v))`：软惩罚可改变路径选择，Lethal/Forbidden Configuration 应作为合法性约束而非“罚得够高就能走”。函数尺度/单位需一致；具体 Nav2 Planner 的函数以源码为准。

### 25. Feasibility / Tracking Margin
计划 Footprint 不碰撞不等于真实运动绝对安全。需要额外考虑 Localization Uncertainty、Tracking Error、Latency、身体姿态变化；控制与动态制动留后续 M13。

### 26. Failure Attribution
`Sensor→Filter→TF→Costmap→Footprint→Planner→Controller→Motion`。根据已知事实缩小范围：若墙体254正确且中心轨迹贴合路径却擦墙，首先核 Footprint 形状/参考点与 Planner 是否按整轮廓/全运动段检查；再核 Yaw/实际轨迹，避免优先反复验证已确认正确的障碍存在性。

### 27. Circle vs Polygon Trade-off
外接圆检查简单、安全保守但容易误封窄路；多边形更准确、可减少保守性，但必须校验 Yaw、顶点、边及 Swept Motion。安全裕量需与真实机器人尺寸/动态姿态配套。

### 28. Owner Invariant
`Free Cell ≠ Collision-Free Footprint ≠ Safe Executable Motion`。必需检查坐标系+时间+完整几何+动态约束的责任链；不能单凭 Path Center 未压254就认定可执行。
