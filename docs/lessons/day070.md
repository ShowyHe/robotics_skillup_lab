## Mastered

- Path represents planned spatial route; Trajectory adds time, velocity and execution state.
- Planner output is not directly executable by the robot because it lacks timing, velocity and dynamic feasibility.
- Smoother optimizes an existing path quality; it is not a replacement for Planner.
- Hybrid A* provides motion-feasible paths, while smoothing improves continuity and controller friendliness.
- Curvature affects robot executability because nonholonomic robots have turning constraints.
- Global replanning solves path-level problems; Controller handles execution-level problems.
