## A. Foundation（01–08）

### 01. Workspace 与 Configuration Space

- Workspace（工作空间）描述机器人及障碍所处的物理空间。
- Configuration（构型） \(\boldsymbol q\) 描述机器人独立的几何自由度；\(\mathcal C\) 是所有构型的集合。
- 平面圆形移动机器人可取 \(\boldsymbol q=(x,y)\)；非圆形底盘通常还需航向 \(\theta\)，即 \((x,y,\theta)\)；六转动关节机械臂常取 \(\boldsymbol q=(\theta_1,\ldots,\theta_6)\)。
- **构型空间的维度由配置自由度决定，不是工作空间维度的同义词。** 若把速度也纳入规划变量，则成为更广义的状态空间规划。

### 02. 禁止碰撞的构型集合

设机器人的几何占据区域为 \(\mathcal R(q)\)，障碍区域为 \(\mathcal O\)。忽略自碰撞之外的附加约束时：

\[
\mathcal C_{\mathrm{obs}}=\{q\in\mathcal C\mid\mathcal R(q)\cap\mathcal O\ne\varnothing\},\qquad
\mathcal C_{\mathrm{free}}=\mathcal C\setminus\mathcal C_{\mathrm{obs}}.
\]

实际配置有效性还可能要求满足关节限位、地形、运动学/任务限制和机械臂自碰撞。**工作空间里看起来空着，不代表对应构型无碰撞。**

### 03. 一个最小几何例子

二维圆形机器人半径为 \(r\)，障碍是一点 \((x_o,y_o)\)。若只考虑此障碍，机器人中心位置 \(q=(x,y)\) 满足

\[
(x-x_o)^2+(y-y_o)^2>r^2
\]

时才不与该点相撞。这里“机器人大小”被折算成构型空间中中心点的禁入区域。这是 Minkowski 膨胀的几何直觉；对任意旋转多边形还必须考虑姿态，不能简单只膨胀一个固定半径。

### 04. State Validity 不等于 Edge Validity

- State Validity：检查候选构型 \(q\) 是否合法。
- Edge/Motion Validity：检查 \(q_a\rightarrow q_b\) 的**整段插值/局部运动**是否保持合法。
- 两端合法，中间仍可能穿过障碍；插值步长过粗也可能漏检。
- 对非完整约束机器人，还应使用满足模型的局部连接/轨迹检查，而不是把任意两点直线相连就判可执行。

### 05. 确定性搜索与采样搜索

Grid A* 在离散邻接图上系统扩展；Sampling-based Planning 在连续构型空间采样候选状态，构造树/路网，并调用有效性检查。后者在高维中常有优势，但不是必然更快、也不天然适合所有窄通道。

### 06. 随机采样、距离与最近节点

\[
q_{\mathrm{rand}}\sim\mathrm{Sample}(\mathcal C),\qquad
q_{\mathrm{near}}=\arg\min_{q\in\mathcal T}d(q,q_{\mathrm{rand}}).
\]

距离 \(d\) 必须契合空间，例如角度需处理周期性；不同单位的关节量若直接等权欧氏距离，可能导致不合理邻近关系。

### 07. Steer、Step Size、Goal Bias

从最近节点沿目标采样方向扩展，最大步长 \(\eta\)：

\[
q_{\mathrm{new}}=\mathrm{Steer}(q_{\mathrm{near}},q_{\mathrm{rand}},\eta).
\]

- Step Size 过大：探索可能快，但窄处容易撞障碍、越过可行区域；过小：节点多、搜索慢。
- Goal Bias：一定比例直接采样目标以推动连接，但偏置过大可能降低探索其他可行通道的机会。
- 这些是**算法参数的影响机制**，具体效果须按地图、距离度量、局部连接器验证。

### 08. 采样规划的完整性术语

“Probabilistically Complete（概率完备）”是指在**规定的可行性与采样/连接条件下**，若有满足假设的可行路径，采样次数趋于无穷时找到路径的概率趋近于 1。不是有限时间必定找到，更不代表路径最优。

## B. Core Theory（09–16）

### 09. RRT（快速探索随机树）的逐步过程

~~~text
T ← {q_start}
重复：
  q_rand ← Sample(C)
  q_near ← Nearest(T, q_rand)
  q_new  ← Steer(q_near, q_rand, η)
  若 StateValid(q_new) 且 MotionValid(q_near → q_new)：
      将 (q_near → q_new) 加入树 T
      若能够合法连到 Goal：返回树上的父指针路径
超出预算：报告未找到（不能直接判定无路）
~~~

近邻索引、碰撞检查、Goal 连接条件以及最大迭代次数都影响实际规划表现。

### 10. RRT 的一个手推例子

取起点 \(A=(0,0)\)、树中已有 \(B=(1,0)\)、采样 \(C=(3,1)\)，扩展步长 \(\eta=1\)。若最近点是 \(B\)，单位方向是 \((2,1)/\sqrt5\)，则：

\[
q_{\mathrm{new}}=B+\frac{1}{\sqrt5}(2,1)
\approx(1.894,0.447).
\]

**只有在**该点与整条 \(B\rightarrow q_{\mathrm{new}}\) 连接都合法时，才能加入树。末端位置合法不能代替中间碰撞检查。

### 11. RRT 为什么不保证最优

基本 RRT 的核心目标是快速找到可行连接；一旦找到目标，未必重构先前绕远的父子关系，因此不保证路径代价随采样增加渐近达到最优。

### 12. RRT* 的 Near / Best Parent / Rewire

RRT* 在成功生成新点后，考虑附近候选节点集合 \(\mathcal N\)：

1. 在可合法连接的邻居中，选择使 \(g(q_{\mathrm{parent}})+c(q_{\mathrm{parent}},q_{\mathrm{new}})\) 最小的父节点；
2. 插入新节点；
3. 对附近原有节点尝试 **Rewire（重新接父节点）**：若经由新节点更低代价且合法，则调整父关系，并更新受影响的后代代价。

需要考虑邻域半径/邻居数量、合法连接与持续优化机制；**RRT* 不只是“把找到的 RRT 路径平滑一下”。**

### 13. RRT* 的渐近最优性

Asymptotic Optimality 指的是：在合适的采样、邻域连接和路径代价等前提下，样本数量趋于无穷时解的代价收敛到最优代价。**有限采样不保证最优**；若状态空间/连接器/代价函数违反理论假设，不能直接套这个保证。

### 14. 窄通道采样困难

若有效通道在构型空间占比很小，均匀随机采样很难抽中；即使采到通道内，局部连接也可能穿过 \(\mathcal C_{\mathrm{obs}}\)。可考虑障碍边界偏置、桥采样、专门局部连接器、改进距离与可行性表示，但不能仅凭“采样次数多”断言会及时通过。

### 15. PRM 和 RRT-Connect（只做概念比较）

| 方法 | 核心构造 | 更典型的使用情形 |
|---|---|---|
| RRT | 从起点生长一棵随机探索树 | 单次起终点查询 |
| RRT* | 树 + 优化父节点/重连 | 同时关注可行性和路径代价 |
| PRM | 采样建路网，再连接查询起终点 | 同一环境多次查询 |
| RRT-Connect | 双向生长两棵树并尝试连接 | 快速寻找可行连接 |

这里只要求概念与适用条件；PRM/RRT-Connect 的正式机制留后续操作规划课程。

### 16. OMPL（Open Motion Planning Library）的职责

OMPL 提供采样式规划器、状态空间/规划问题建模以及 StateValidityChecker、MotionValidator 等扩展接口。**障碍物的语义和真正的碰撞检测通常要由使用方/上层系统提供**，不能认为 OMPL 自己就知道真实地图障碍在哪里。MoveIt 等上层工具可以把机械臂碰撞检查与 OMPL 规划连接起来。

## C. Advanced / Owner（17–21）

### 17. 从机器人真实几何到采样可行性

~~~text
Map/PointCloud/Costmap + Robot Geometry + Current State
                         ↓
                 Configuration validity
                         ↓
          Motion validity / local connector
                         ↓
             RRT/RRT* feasible path
                         ↓
           Dynamics/Control feasibility check
~~~

对于普通底盘，旋转 Footprint 的碰撞判断不能仅靠中心点；对于机械臂则涉及关节限位、连杆自碰撞及与环境碰撞。

### 18. 规划路径与可执行轨迹不要混为一谈

RRT/RRT* 输出的是经其规划约束定义的路径；若规划状态仅含构型，路径合法不代表速度、加速度、时序和底盘跟踪能力满足要求。是否需要后处理取决于具体规划器、模型与控制架构。

### 19. 高维操作规划连接

机械臂 \(q\in\mathbb R^n\) 下，每个采样是一组关节角，而不是末端 XYZ 点。检验一条边须检查整段关节插值的连杆碰撞。这解释了为什么 C-space 思想是 MoveIt/OMPL 操作规划的基础。

### 20. 性能与失败证据

规划失败时先检查采样预算、goal bias、最近邻度量、有效状态比例、局部连接器、碰撞检测分辨率，以及终点是否本身有效；不要只用“RRT 不够强”归因。

### 21. 教学迁移题（新增练习，不属于历史考试）

- 已知起点和终点都无碰撞，但连线穿过墙：State Validity 与 Motion Validity 分别得到什么结论？
- RRT* 新点使一个邻居的累计代价下降，但新边与障碍相交：能否 Rewire？
- 六轴机械臂的采样点是“末端空间坐标”还是“关节构型”？

**参考判断：** 首尾状态有效而运动边无效；禁止重连；通常是关节构型（除非另行选择任务空间规划变量）。

## Key Knowledge

1. Configuration Space transforms robot motion planning into searching robot configurations.

2. C_obs represents configurations causing collision. C_free represents collision-free configurations.

3. Collision checking in C-space includes robot footprint, obstacle geometry and robot pose.

4. Sampling-based planners avoid exhaustive grid search in large continuous spaces.

5. RRT (Rapidly-exploring Random Tree) grows a tree by sampling random configurations and extending toward them.

6. RRT is probabilistically complete but not guaranteed optimal.

7. RRT* adds rewiring to improve path cost after new nodes are added.

8. Rewire is the key difference: connect nearby nodes through a lower-cost parent when possible.

9. OMPL (Open Motion Planning Library) provides common sampling-based planning algorithms and collision checking interfaces.

## Engineering Mapping

For robot navigation:

Costmap / footprint collision
→ configuration validity checking
→ planner expansion
→ feasible trajectory

Sampling methods are useful when state space becomes complex, such as high-dimensional planning.
