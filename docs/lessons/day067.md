## Key Knowledge

1. Configuration Space transforms robot motion planning into searching robot configurations.

2. C_obs represents configurations causing collision. C_free represents collision-free configurations.

3. Collision checking in C-space includes robot footprint, obstacle geometry and robot pose.

4. Sampling-based planners avoid exhaustive grid search in large continuous spaces.

5. RRT (Rapidly-exploring Random Tree) grows a tree by sampling random configurations and extending toward them.

6. RRT is probabilistically complete but not guaranteed optimal.

7. RRT* adds rewiring to improve path cost after new nodes are added.

8. Rewire is the key difference: connect nearby nodes through a lower-cost parent when possible.

9. OMPL (Open Motion Planning Library) provides common sampling-based planning algorithms and collision checking interfaces.

## Engineering Mapping

For robot navigation:

Costmap / footprint collision
→ configuration validity checking
→ planner expansion
→ feasible trajectory

Sampling methods are useful when state space becomes complex, such as high-dimensional planning.
