## 1. Scalar、Vector、Matrix

### 1.1 Scalar — 标量

Scalar 只有一个数，例如：

- 机器人线速度 `v=0.3 m/s`；
- 温度 `25°C`；
- yaw angle `0.5 rad`。

数学上写作：

`v ∈ R`

### 1.2 Vector — 向量

多个量可以组成一个整体状态。例如二维移动机器人常写：

```text
x = [p_x, p_y, θ]^T ∈ R^3
```

这里的“三维”是状态向量有 3 个分量，而不是说机器人一定在三维空间运动。

例如：

```text
x = [p_x, p_y, θ, v_x, ω_z]^T ∈ R^5
```

机器人仍可在二维地面运动，但 state 已经是五维。

因此：

> Vector dimension = 描述该数学对象所需的独立分量数量。

### 1.3 Matrix — 矩阵

例如：

```text
A = [[1,2],
     [3,4]] ∈ R^(2×2)
```

`A∈R^(m×n)` 表示：

- m 行；
- n 列。

但矩阵更重要的理解不是“数字表格”，而是：

> 一个 `m×n` 矩阵可以表示从 `R^n` 到 `R^m` 的线性映射。

即：

`A : R^n → R^m`

---

## 2. Vector 不只是“一串数字”

例如：

```text
x = [2, 3, 0.5]^T
```

如果没有变量定义，这三个数字本身并不能说明状态含义。

如果定义：

```text
x = [p_x, p_y, θ]^T
```

才知道：

- `p_x = 2 m`；
- `p_y = 3 m`；
- `θ = 0.5 rad`。

因此以后阅读 EKF / SLAM / Controller 源码，首先要确认：

> state vector 每一维是什么、单位是什么、属于哪个 frame。

例如：

```text
x = [p_x,p_y,v_x,v_y,θ,b_g]^T
```

和：

```text
x = [p_x,p_y,p_z,v_x,v_y,v_z,q_x,q_y,q_z,q_w]^T
```

虽然都叫 `x`，物理含义完全不同。

---

## 3. Row Vector 与 Column Vector

机器人算法通常默认使用 column vector。

例如：

```text
x = [1,2,3]^T
```

其矩阵形状是：

`3×1`

转置后：

```text
x^T = [1,2,3]
```

形状变成：

`1×3`

所以写 `x∈R^3` 时，机器人公式通常默认把它作为三维列向量使用。

注意：

> 向量不一定“只有一行”；机器人公式中反而更常见列向量。

---

## 4. Matrix Addition 与 Scalar Multiplication

矩阵相加必须 shape 完全一致。

若：

`A,B ∈ R^(m×n)`

才可以做：

`A+B`

例如：

```text
[[1,2],      [[5,6],      [[6,8],
 [3,4]]  +   [7,8]]   =   [10,12]]
```

标量乘矩阵则是每个元素都乘同一个 scalar，例如：

```text
2A = [[2,4],
      [6,8]]
```

Day8 的重点不在这里，而在 matrix multiplication。

---

## 5. Matrix × Vector：到底在做什么

设：

```text
A = [[1,2],
     [3,4]]

x = [2,1]^T
```

那么：

```text
Ax = [1×2 + 2×1,
      3×2 + 4×1]^T
   = [4,10]^T
```

### 5.1 从列向量组合来看

把 A 写成列：

```text
A = [a1  a2]
```

其中：

```text
a1 = [1,3]^T
a2 = [2,4]^T
```

则：

`Ax = x1 a1 + x2 a2`

本例：

```text
Ax = 2[1,3]^T + 1[2,4]^T
   = [4,10]^T
```

所以：

> Matrix × Vector 本质上是用输入 vector 的各分量，对 matrix 的 columns 做线性组合。

这个理解会直接连接 Day9 的 basis、rank、null space，也会连接 Neural Network 的 `Wx+b`。

---

## 6. Matrix Multiplication 的 dimension 规则

若：

`A ∈ R^(m×n)`

`B ∈ R^(n×p)`

则：

`AB ∈ R^(m×p)`

可以记为：

```text
(m×n)(n×p) → (m×p)
```

中间两个 n 必须相等。

例如：

```text
(3×4)(4×2) → 3×2
```

更准确的说法是：

> A 的列数必须等于 B 的行数。

### 6.1 为什么必须这样？

若：

`A : R^4 → R^3`

那么 A 的输入必须属于 `R^4`。

若要计算 `AB`，B 的每一个 column 都要作为 A 的输入，所以 B 的每个 column 也必须是 4 维，因此 B 必须有 4 行。

这说明 dimension rule 不是死背出来的，而是由 mapping 的输入输出空间决定。

---

## 7. Matrix Multiplication 一般不满足交换律

普通数字满足：

`ab = ba`

但矩阵一般：

`AB ≠ BA`

甚至可能：

- `AB` 可以计算；
- `BA` 根本不合法。

例如：

```text
A: 3×4
B: 4×2
```

那么：

`AB: 3×2`

成立。

但：

```text
BA = (4×2)(3×4)
```

中间 `2≠3`，因此不能计算。

这会直接影响后面的 TF / Camera transform 连乘顺序。

---

## 8. Matrix 作为 Function / Linear Mapping

Day8 最重要的概念之一是：

`y = Ax`

如果：

`A ∈ R^(3×2)`

那么：

`x ∈ R^2`

输出：

`y ∈ R^3`

所以：

`A : R^2 → R^3`

即 A 是一个从二维输入空间映射到三维输出空间的 linear mapping。

### 8.1 为什么不能把 `y=Ax` 只理解成“坐标转换”？

因为 linear mapping 的用途远比 coordinate transform 广。

A 可能表示：

- coordinate transformation；
- rotation；
- scaling；
- projection；
- state transition；
- measurement extraction；
- neural-network feature mapping。

而且线性映射既可能改变维度，也可能保持维度不变。

因此更准确的理解是：

> `y=Ax` 表示 A 根据某种线性关系，把输入 x 映射为输出 y。

---

## 9. Robot Mapping ①：State Transition

以后状态估计和控制中会看到：

`x_(k+1) = A x_k`

这里 A 表示：

> 当前 state 如何线性影响下一时刻 state。

Day8 不展开动态系统，只建立矩阵作为 state mapping 的直觉。

---

## 10. Robot Mapping ②：Measurement Matrix

设机器人状态：

```text
x = [p_x,p_y,v_x,v_y]^T ∈ R^4
```

GPS 只测位置：

```text
z = [p_x,p_y]^T ∈ R^2
```

可以写：

`z = Hx`

其中：

```text
H = [[1,0,0,0],
     [0,1,0,0]] ∈ R^(2×4)
```

那么：

```text
Hx = [p_x,p_y]^T
```

所以 H 的物理含义是：

> 从完整 4D state 中提取前两个 position components。

如果状态：

```text
x = [x,y,θ,v]^T
```

传感器只测 `θ`，则：

```text
H = [0,0,1,0]
```

这里 H 放的是线性系数，不是把 `θ` 本身写进 H。

这个思想以后会进入 EKF measurement model，但 Day8 只要求理解 matrix mapping。

## 11. Robot Mapping ③：Neural Network Linear Layer

神经网络线性层：

`y = Wx + b`

假设：

```text
x ∈ R^128
W ∈ R^(64×128)
```

则：

```text
Wx ∈ R^64
```

即：

```text
128D feature
→ W
→ 64D feature
```

本质仍然是 Day8 的 matrix mapping。

---

## 12. Transpose — `A^T`

设：

```text
A = [[1,2,3],
     [4,5,6]]
```

则：

```text
A^T = [[1,4],
       [2,5],
       [3,6]]
```

如果：

`A ∈ R^(2×3)`

那么：

`A^T ∈ R^(3×2)`

Transpose 的本质：

> 行列互换。

它本身并不表示“撤销一个变换”。

---

## 13. Identity Matrix — `I`

二维单位矩阵：

```text
I2 = [[1,0],
      [0,1]]
```

三维单位矩阵：

```text
I3 = [[1,0,0],
      [0,1,0],
      [0,0,1]]
```

满足：

`Ix = x`

所以 Identity Matrix 可以理解为：

> 什么都不改变的线性映射。

类似普通数字乘法中的：

`1×x = x`

### 13.1 Identity Matrix ≠ Unit Vector

Unit vector 满足：

`||u|| = 1`

它表示一个长度为 1 的方向。

Identity matrix 是 matrix；unit vector 是 vector，两者不是同一类对象。

---

## 14. Inverse Matrix — `A^-1`

若 A 可逆，则：

`A^-1 A = A A^-1 = I`

如果：

`y = Ax`

左乘 `A^-1`：

`A^-1 y = A^-1 A x = Ix = x`

所以：

`x = A^-1 y`

几何直觉：

```text
x --A--> y

y --A^-1--> x
```

即：

> inverse 用于撤销一个可逆的 linear transformation。

---

## 15. 为什么并非所有 Matrix 都有 Inverse？

考虑：

```text
A = [[1,0],
     [0,0]]
```

输入：

```text
x = [x1,x2]^T
```

输出：

```text
Ax = [x1,0]^T
```

这意味着输入中的 `x2` 信息完全消失。

例如：

```text
[2,1]^T
```

和：

```text
[2,100]^T
```

经过 A 后都会得到：

```text
[2,0]^T
```

所以拿到输出 `[2,0]^T` 时，不可能唯一恢复原来的 `x2`。

因此：

> Mapping 一旦丢失独立信息，就无法通过 inverse 唯一反解原输入。

这就是“不可逆”的核心信息直觉。

Day9 会用 rank / null space 描述这种信息丢失；Day12 会用 SVD / singular value 进一步描述。

---

## 16. Square Matrix 与 Invertibility

普通 matrix inverse `A^-1` 首先要求 A 是 square matrix：

`A ∈ R^(n×n)`

但：

> Square matrix 不代表一定可逆。

例如：

```text
A = [[1,2],
     [2,4]]
```

虽然是 `2×2`，第二行只是第一行的 2 倍，独立信息不足，因此不可逆。

完整判断后续结合 rank 学习。

---

## 17. `A^T` 与 `A^-1` 的区别

### Transpose

`A^T`：行列互换。

### Inverse

`A^-1`：撤销可逆 mapping。

一般情况下：

`A^T ≠ A^-1`

但以后会遇到 rotation matrix：

`R^-1 = R^T`

这是 orthogonal / rotation matrix 的特殊性质，不是一般矩阵都满足。

## 18. Day8 的固定读公式方法

以后看到：

`y = Ax`

不要直接开始计算，固定做四步：

### Step 1：变量是什么？

例如：

```text
x = robot state
y = measurement
A = mapping
```

### Step 2：dimension 是否成立？

例如：

```text
x ∈ R^4
A ∈ R^(2×4)
```

所以：

```text
y ∈ R^2
```

### Step 3：数学操作是什么？

这里是 linear mapping。

### Step 4：物理含义是什么？

A 到底是在：

- selecting state；
- rotation；
- projection；
- state propagation；
- feature mapping；
- coordinate transformation？

这种读法会贯穿后面的 Vision / EKF / SLAM / Control。

## 20. Day8 核心结论

必须真正掌握的不是一组死记规则，而是：

1. Vector 是状态或物理量的多维表示；
2. Matrix 可理解为从一个 vector space 到另一个 vector space 的 linear mapping；
3. Matrix multiplication 首先要检查 dimension；
4. `Ax` 可以理解为 A 的 columns 按 x 各分量做线性组合；
5. `A^T`、`I`、`A^-1` 是三个不同概念；
6. Mapping 丢失独立信息时无法唯一反解，因此 inverse 不存在；
7. 阅读机器人公式必须同时检查 variable meaning、dimension、mapping semantics。
