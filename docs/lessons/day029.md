## 1. 核心结论

训练真正优化的是：

\[
\boxed{\min_\theta J(\theta)}
\]

Loss / Objective（损失 / 目标函数）是训练目标；Gradient（梯度）只是寻找更低 Loss 的局部方向信息。

\[
\boxed{\text{Loss 是目标，Gradient 是工具}}
\]

## 2. 完整训练循环

\[
\theta_k
\rightarrow
Forward
\rightarrow
L_k
\rightarrow
Backward
\rightarrow
\nabla_\theta L_k
\rightarrow
Optimizer
\rightarrow
\theta_{k+1}
\]

得到新参数后必须重新 Forward，重新计算新的 Loss。负梯度更新并不保证每一步实际 Loss 都下降。

## 3. Gradient Descent（梯度下降）

\[
\theta_{k+1}=\theta_k-\alpha\nabla_\theta L
\]

- \(\theta\)：Parameter（参数）
- \(\alpha\)：Learning Rate（学习率）
- \(\nabla_\theta L\)：Loss 对参数的局部敏感度和方向信息

负梯度是当前位置的一阶局部下降方向。

## 4. Learning Rate（学习率）

Learning Rate 决定沿当前方向走多远。

- 太大：Overshoot（过冲）、Oscillation（振荡）、Divergence（发散）
- 太小：Convergence（收敛）过慢

## 5. Gradient 小不等于 Loss 小

\[
\|\nabla L\|\approx0
\]

只能说明当前位置一阶变化较小，可能位于较好的 Minimum（最小值），也可能是差的 Local Minimum（局部最小值）、Saddle Point（鞍点）或 Flat Plateau（平坦区域）。

所以训练目标不是让 Gradient 越来越小。

## 6. Full Batch / Mini-batch

Full Batch（全批次）每次使用整个 Dataset（数据集）。

Mini-batch（小批次）每次只使用一部分 Sample（样本）：

\[
g_{batch}\neq\nabla J
\]

因此 Mini-batch Gradient 是整体梯度的估计，不同 Batch 会带来 Gradient Noise（梯度噪声）。

## 7. Batch / Iteration / Epoch

Dataset 有 2400 个 Sample，Batch Size 为 100：

\[
1\ Epoch=24\ Batch=24\ Iteration
\]

训练 10 Epoch：

\[
240\ Iteration
\]

## 8. Training Loop 正确顺序

zero_grad()
→ forward
→ compute loss
→ loss.backward()
→ optimizer.step()

loss.backward() 负责计算各 Parameter 的 Gradient，不直接修改 Parameter。

optimizer.step() 读取 Gradient，并根据 Optimizer 规则更新 Parameter，不是“更新 Learning Rate”。

## 9. zero_grad()

PyTorch 中 Parameter.grad 默认会累加。普通 Mini-batch 训练通常在每个 Iteration 开始清理上一轮 Gradient。

这与同一个计算图内多条路径的梯度贡献相加不是一回事。

## 10. Momentum（动量）

Momentum 利用当前和历史 Gradient 的趋势形成更稳定的更新方向：

\[
v_k=\beta v_{k-1}+g_k
\]

\[
\theta_{k+1}=\theta_k-\alpha v_k
\]

## 11. Adam（Adaptive Moment Estimation，自适应矩估计）

Adam 利用 Gradient 的一阶矩估计和二阶矩估计，为不同 Parameter 形成不同的有效更新尺度。

目标仍然是更有效地优化 Loss，不是让 Gradient 本身变小。

## 12. Learning Rate Schedule（学习率调度）

包括 Learning Rate Decay（学习率衰减）和 Warmup（预热），用于不同训练阶段调整更新步长。

## 13. Gradient Explosion / Vanishing

Gradient Explosion（梯度爆炸）：梯度异常大，可能导致参数跳飞、Loss 剧烈震荡甚至 NaN。

Gradient Vanishing（梯度消失）：梯度过小，早期 Layer（层）几乎收不到有效学习信号。

## 14. Gradient Clipping（梯度裁剪）

Gradient Clipping 主要限制异常大的 Gradient 幅值，防止一次 Parameter Update 过大。

它不是把 Gradient 当成错误数据直接删除，更接近“限制更新幅度”。
