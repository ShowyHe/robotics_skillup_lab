## 2. Expectation（期望）

离散随机变量：

E[X] = sum_i x_i P(X=x_i)

连续随机变量：

E[X] = integral x p(x) dx

Expectation 表示随机变量长期平均趋向的位置，不代表下一次观测一定等于该值。

## 3. Variance / Standard Deviation

Variance：

Var(X) = E[(X-mu)^2]

Standard Deviation：

sigma = sqrt(Var(X))

Variance 描述随机变量围绕均值的分散程度；标准差与原变量单位一致。

## 4. Covariance（协方差）

两个随机变量 X、Y：

Cov(X,Y) = E[(X-mu_X)(Y-mu_Y)]

含义：
- Cov > 0：两者偏差倾向同向变化
- Cov < 0：两者偏差倾向反向变化
- Cov ≈ 0：没有明显线性共同变化关系

零协方差不一般等价于完全独立。

## 5. Covariance Matrix（协方差矩阵）

二维状态：

x = [x, y]^T

Sigma =
[ Var(x)    Cov(x,y)
  Cov(y,x) Var(y) ]

其中：
- 对角线：各状态自身方差
- 非对角线：Cross-covariance（交叉协方差）

协方差矩阵满足对称性：

Sigma = Sigma^T

一般若 state 属于 R^n，则：

Sigma 属于 R^(n×n)

## 6. Units（单位）

若：
- x、y 单位为 m
- theta 单位为 rad

则：
- Var(x)：m^2
- Var(theta)：rad^2
- Cov(x,theta)：m·rad

不同矩阵元素单位可以不同。

## 7. Gaussian Distribution（高斯分布）

一维：

X ~ N(mu, sigma^2)

其中：
- mu：Mean（均值）
- sigma^2：Variance（方差）

sigma 越小，分布越集中；sigma 越大，不确定性越大。

## 8. Multivariate Gaussian（多元高斯）

机器人状态：

x ~ N(mu, Sigma)

其中：

mu：
- 状态估计的中心 / 期望

Sigma：
- 各状态有多不确定
- 各状态误差之间如何相关

完整状态估计不是只维护 state estimate，还需要维护 uncertainty structure（不确定性结构）。

## 9. Covariance Ellipse（协方差椭圆）

对于二维协方差矩阵 Sigma：

Sigma v_i = lambda_i v_i

其中：
- Eigenvector（特征向量）v_i：协方差椭圆主轴方向
- Eigenvalue（特征值）lambda_i：该主轴方向上的方差
- 轴的标准差尺度更直接与 sqrt(lambda_i) 相关

这是 Day11 Eigenvalue / Eigenvector 在机器人不确定性中的实际连接。

## 10. Correlation（相关系数）

定义：

rho_XY = Cov(X,Y) / (sigma_X sigma_Y)

性质：
- 范围 [-1,1]
- 无单位

边界：

Covariance：
- 有物理单位
- 描述共同变化规模

Correlation：
- 无单位
- 是标准化后的线性相关强度

## 11. Systematic Bias vs Covariance

Covariance 小不代表 Actual Error 小。

例如 GNSS 长期稳定输出 100m，但真实位置是 105m：

- Covariance 可以很小
- Actual Error 仍然是 5m

这种情况属于：

Systematic Bias（系统偏差）

因此：

Covariance Small != Localization Accurate

## 12. State Vector + Covariance Matrix

后续 Kalman Filter / EKF 会同时维护：

State Estimate：

x_hat

以及：

Covariance Matrix：

P

例如：

x_hat = [x, y, vx, vy]^T

P 属于 R^(4×4)

含义：

“机器人估计在哪里 / 状态是多少”
+
“这个估计有多不确定”
+
“各状态误差之间如何相关”
