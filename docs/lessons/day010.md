# M02 · Day10 — 范数、点积、投影、叉积与几何关系

## 今日目标
掌握机器人算法中高频使用的向量几何工具：长度、距离、夹角、投影、正交、叉积、法向量，并能解释它们在导航、视觉、点云和 ICP 中的物理意义。

> 记号约定：为避免把点积与矩阵乘法混淆，本讲义优先写 `a·b` 表示点积；对实列向量有 `a·b = a^T b`。

---

## 1. 向量范数
对二维向量 `x=[x1,x2]^T`：

`||x||_2 = sqrt(x1^2+x2^2)`。

它表示向量长度。若 `v=[vx,vy]^T` 是速度向量，则 `||v||` 是速度大小，方向信息被去掉。

## 2. 两点之间的欧氏距离
两点 `p1,p2` 的距离：

`d = ||p2-p1||`。

先相减得到“从 p1 指向 p2 的位移向量”，再求长度。导航中的 goal distance、path distance、obstacle clearance 都常以此为基础。

## 3. 点积
对实向量 `a,b`：

`a·b = ||a|| ||b|| cos(theta)`。

点积结果是标量，不是新的向量，也不是把一个向量线性变换成另一个向量。

几何意义：衡量两个方向有多一致。
- `theta=0°`：同向，点积为正且最大；
- `theta=90°`：正交，点积为 0；
- `theta=180°`：反向，点积为负。

若 `a,b` 非零，可由

`theta = arccos((a·b)/(||a||||b||))`

求夹角。

## 4. 标量投影与投影向量
先令 `b_hat=b/||b||` 为单位方向。

### 标量投影
`a·b_hat`

表示 a 在 b 方向上有多少“有符号长度”。

### 投影向量
`proj_b(a) = (a·b_hat)b_hat = ((a·b)/(b·b))b`

它才是实际落在 b 方向上的向量。

例：`a=[3,4]^T`，`b=[1,0]^T`。
- 标量投影 = 3；
- 投影向量 = `[3,0]^T`。

## 5. 投影的机器人意义
若 `v` 是机器人速度、`t` 是路径单位切向，则 `v·t` 表示沿路径方向的有效速度。

若 `e=r-p` 是机器人相对路径的误差向量、`n` 是路径单位法向，则 `e·n` 是横向误差。

## 6. 正交
若 `a·b=0` 且二者非零，则 `a⊥b`。

原因来自 `a·b=||a||||b||cos(theta)`，非零向量长度不为 0，因此只有 `cos(theta)=0`，也就是 `theta=90°`。

## 7. 旋转矩阵为什么满足 R^-1 = R^T
二维旋转矩阵的两列 `r1,r2` 是标准基旋转后的新基。

旋转只改变方向：
- `||r1||=||r2||=1`；
- `r1·r2=0`。

于是：

`R^T R = [[r1·r1, r1·r2],[r2·r1, r2·r2]] = I`。

因此 `R^-1=R^T`。

几何上：R 的列是一组单位正交基；用这组基分别与向量做点积，就能取回该向量在各基方向上的分量，因此转置恰好完成逆操作。

## 8. 叉积
对 `a,b∈R^3`：

`a×b`

得到一个同时垂直于 a、b 的向量，长度为：

`||a×b|| = ||a||||b||sin(theta)`。

方向由右手定则确定，且 `a×b=-(b×a)`。

例：
`[1,0,0]^T × [0,1,0]^T = [0,0,1]^T`。

## 9. 法向量
平面内两个不共线方向 a、b 的叉积 `n=a×b` 给出平面法向方向。法向量垂直于表面。

## 10. Point-to-Plane ICP 的几何意义
设 `e=p-q` 是点误差，`n` 是单位法向量，则：

`n·(p-q)`

是误差向量在法向方向上的标量投影。若 `||n||=1`，它就是有符号法向距离，也就是点到局部平面的法向距离误差。

注意：这里是点积，不是“n 对 (p-q) 做线性变换”。

## 11. 导航/控制中的统一几何量
- 目标距离：`||p-p_goal||`
- 障碍距离：`||p-p_obs||`
- 方向一致性：`a·b`
- 夹角：由归一化点积求 `arccos`
- 横向误差：`e·n`
- 有效前进速度：`v·t`
- 点到平面误差：`n·(p-q)`

## 12. 统一判断规则
看到向量几何问题时：
1. 求长度 → 范数；
2. 求两点距离 → 先相减再范数；
3. 求夹角/方向一致性 → 点积；
4. 求某方向上的分量 → 投影；
5. 判断垂直 → 点积是否为 0；
6. 三维构造垂直方向 → 叉积；
7. 点离平面多远 → 对单位法向量做标量投影。
