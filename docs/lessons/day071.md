## 2. Goal and Concept Chain
建立刚体/关节构型和刚体瞬时运动、受力的统一描述：
Configuration（构型）→ Rigid Transform（刚体变换）→ Screw Axis（螺旋轴）→ Twist（运动旋量）↔ Wrench（力旋量）。
目标深度：Configuration L4，Screw/Twist L3–L4，Wrench L3（契约目标，不代表经独立实现验证的个人能力等级）。

## 3. SE(3) Entry Bridge（刚体变换入口桥）
1. Rigid Body（刚体）：运动中刚体内部各点距离不变的理想模型。
2. Frame（坐标系）：明确 Space Frame（空间坐标系）、Body Frame（本体坐标系）、Base Frame（基座坐标系）和 End-Effector Frame（末端执行器坐标系）。物理运动与坐标表达不可混同。
3. Rotation Matrix（旋转矩阵）：`R ∈ SO(3)`，`RᵀR=I`，`det(R)=1`。描述方向，不含平移。`R_sb` 把在 b 中表达的向量映射到 s。
4. Homogeneous Transform（齐次变换）：`T_sb=[R_sb p_sb; 0 1]`，4×4；`p_s=R_sb p_b+p_sb`；`T_sc=T_sb T_bc`；`T_bs=[R_sbᵀ, -R_sbᵀp_sb; 0, 1]`。矩阵乘法顺序不可交换。
5. SO(3)（三维特殊正交群）表示三维旋转；SE(3)（三维特殊欧氏群）表示刚体旋转和平移。SE(3) 不是“四维旋转群”，4×4 仅是齐次矩阵表达格式。
6. Hat Operator（反对称矩阵算子）：`[ω]×p=ω×p`；Exponential Map（指数映射）从局部刚体运动增量构造合法刚体变换，`exp([S]θ)`。本桥不等于 M08 Day46–48 已完成。

## 4. Foundation（基础层）
7. Link（连杆）、Joint（关节）、DOF（自由度）：Revolute Joint（旋转关节）、Prismatic Joint（移动关节）、Fixed Joint（固定关节）；DOF 由独立关节变量与约束确定。
8. Configuration（构型）：关节配置 `q=[q1,...,qn]ᵀ`，各维按关节类型采用 rad 或 m；Configuration Space（构型空间）为所有允许配置的集合，Joint Limit（关节限位）约束允许范围。
9. Pose（位姿）描述指定刚体/末端相对指定 Frame 的位置与方向，**不是仅位置**；Configuration 不等于 Pose，也不等于包含速度的完整运动状态。不同 `q` 可产生相同末端位置但不同姿态。
10. Kinematic Chain（运动学链）与 Kinematic Tree（运动学树）：关节连接刚体，URDF（Unified Robot Description Format，统一机器人描述格式）描述父子 Link、Joint、坐标和限位。四足机器人存在多分支树结构。

## 5. Core Theory（核心理论）
11. Screw Motion（螺旋运动）：绕一条轴旋转、可同时沿轴平移；纯旋转与纯平移是特例。
12. Screw Axis（螺旋轴）：本课采用 Modern Robotics 的 angular-first convention（角分量在前）`S=[ω;v]∈ℝ⁶`；旋转轴上一点 `r`（m）、Pitch（螺距）`h`（m/rad）时，`v=-ω×r+hω`。纯旋转 `h=0`。
13. 旋转关节算例：`ω=(0,0,1)ᵀ`、`r=(1,0,0)ᵀ m`，有 `ω×r=(0,1,0)ᵀ`，因此 `S=(0,0,1,0,-1,0)ᵀ`。位置向量顺序不能写反。
14. Prismatic Joint（移动关节）只平移，如沿 +Z，则 `S=(0,0,0,0,0,1)ᵀ`；前三维为零因为没有旋转，不是因为“经过原点”。
15. Twist（运动旋量）描述刚体**瞬时运动**。旋转关节 `V=S·θ̇`；Space Twist（空间运动旋量）`V_s=[ω;v]`，上三维 rad/s，下三维 m/s。其线性分量并非任意指定末端点的速度。
16. 同一空间 Frame 中，刚体任意点 `p`（m）的实际速度 `ṗ=ω×p+v`；例如 `ω=(0,0,1) rad/s`、`r=(1,0,0)m`、`v=(0,-1,0)m/s`，点 `p=(2,0,0)m` 速度为 `(0,1,0)m/s`。
17. Twist 的六维数值依赖 Frame（坐标系）、原点及方向；同一物理运动换 Frame 后需要相应变换。Space/Body 的严格 Adjoint 在 Day73 正式展开。
18. Wrench（力旋量）采用 `F=[m;f]∈ℝ⁶`：`m` 是相对于声明参考点的 Moment（力矩，N·m），`f` 是 Force（力，N）。在参考原点到施力点向量 `r` 下，`m=r×f`，**不能写成 `f×r`**。
19. 例：`r=(2,0,0)m`，`f=(0,5,0)N`，`m=(0,0,10)N·m`；移动参考点可能改变力矩表示，不改变实际施加的力。
20. Twist–Wrench Power（运动旋量与力旋量的功率对偶）：兼容 Frame、同一参考点及符号约定下，`P=FᵀV=m·ω+f·v`，单位 W（功率）；`8 W` 持续 `1 s` 对应做功 `8 J`。

## 7. Quiz and Evidence（初测、纠错与复测）
### 原始 Quiz（9 题，未记录正式总分）
- Q1 Configuration/Pose：最初将 Pose 当成仅有位置、`q` 当成运动状态；后经定向复测，能分辨位置相同、朝向不同则 Pose 不同。
- Q2 Rigid Transform：`R_z(90°)`、`t=(1,2,0)m`、`p_b=(1,0,0)m`，正确算出 `p_s=(1,3,0)m`。
- Q3 SO(3)/SE(3)：最初把 SE(3) 说成平移矩阵/四维旋转矩阵；补充齐次矩阵的旋转+平移意义，并重申 4×4 不代表四维旋转。
- Q4 Screw Axis：最初 `v` 符号写反；补讲 `v=-ω×r`。
- Q5 Prismatic Joint：六维数值正确但理由错；复测说明没有旋转所以 `ω=0`。
- Q6 Twist：初次不会；复测正确 `S=(0,0,1,0,-2,0)`、`θ̇=2 rad/s` → `V=(0,0,2,0,-4,0)`，并理解点速度必须用 `ω×p+v`。
- Q7 Frame：初始理由简略，后指出换 Frame 需要坐标变换。
- Q8 Power：算得 8 W；最初混淆功和功率，复测回答 8 W 持续 1 s 做功 8 J。
- Q9 Owner：能先检查机械臂坐标、末端变换、关节构型和 Twist Frame，再考虑 Controller。
### 后续定向复测
- Twist 场点速度：回答 `(2-1)×1=1 m/s`，补全向量为 `(0,1,0)m/s`；能解释 Twist 是刚体速度场而非某个点的速度，此 Hard Gate 通过。
- Configuration/Pose：明确两组末端位置相同但朝向不同，则 Pose 不同；通过。
- Wrench/Moment：曾反复将 `f×r` 写成力矩公式；最终在新题独立回答 `r=(2,0,0)m`、`f=(0,5,0)N`，`m=(0,0,10)N·m`；通过。
