## 2. 核心讲义

### 2.1 多变量函数与偏导

以二维位置代价为例：

```text
J(x,y)=(x-2)^2+4(y-1)^2
x,y∈R，位置单位 m；J∈R，单位 m²。
```

偏导表示在当前工作点固定其他独立输入，只考察一个输入变化对输出的局部影响：

```text
∂J/∂x=2(x-2)=2x-4
∂J/∂y=8(y-1)=8y-8
```

固定 y 求 x 偏导时，纯 y 项的偏导为 0；这不意味着真实机器人运动时 y 永远不变。普通导数处理单一自变量，多变量函数通常使用偏导。偏导单位为代价单位除以对应输入单位。

### 2.2 梯度、方向与点积

梯度把标量代价对所有独立输入的一阶偏导收集成列向量：

```text
∇J=[∂J/∂x, ∂J/∂y]^T∈R²
∇J(3,3)=[2,16]^T
```

梯度是敏感度向量，不是代价值，也不是底盘速度。若 d 为单位方向向量，则方向导数为 `D_d J=∇J·d=||∇J||cosθ`。因此非零梯度的方向给出单位长度下最快局部上升方向，负梯度给出最快局部下降方向。这一结论直接连接 Day10 点积与投影。若梯度为零，不能仅凭此判断为最小值。

### 2.3 为什么需要梯度下降

只知道当前代价大小，不足以决定下一步如何调整优化变量。以 `J(p)=(p-2)^2` 为例：

```text
J'(p)=2(p-2)
p_new=p-αJ'(p)，α>0
```

当 p=3 时，J'=2，增大 p 会使 J 局部增大，应减小 p。当 p=1 时，J'=-2，增大 p 会使 J 局部减小，应增大 p。减号表示沿增长方向的反方向更新；“下降”指代价下降，不是变量数值必须变小。`p+αJ'(p)` 是局部上升更新。

α 是更新步长系数，控制沿给定方向调整的幅度；不是传感器参数、实际速度或时间间隔。取 α=0.25：p=3 时更新到 2.5，代价 1→0.25；p=1 时同样更新到 1.5，代价 1→0.25。步长过大可能跨过低代价区域甚至使代价上升。该公式更新优化变量，不等于向底盘直接发送速度命令。若位置单位为 m、代价为 m²，直接使用此物理量形式时 α 的单位为 m^-2；一般优化还需按变量和代价单位检查更新维度。

二维更新：

```text
p_new=p-α∇J(p)
p=[3,3]^T，∇J=[2,16]^T，α=0.05 m^-2
p_new=[2.9,2.2]^T
J_old=17，J_new=6.57
```

### 2.4 链式法则：多层依赖的局部影响

若 `z=g(x)`、`L=f(z)`，则：

```text
dL/dx=(dL/dz)(dz/dx)
```

意思是：输入对中间量的影响 × 中间量对最终输出的影响 = 输入对最终输出的局部影响。多层计算图只是依赖关系，不是新运算符；先正向求各中间值，再求各层局部导数并相乘。

例一：`z=3x-1`，`L=z²`：

```text
dz/dx=3
dL/dz=2z
dL/dx=6(3x-1)=18x-6
x=2 → dL/dx=30
```

例二：`z=x²`，`w=3z`，`L=(w-6)²`。在 x=1 时，z=1、w=3、L=9：

```text
dz/dx=2
dw/dz=3
dL/dw=-6
dL/dx=(-6)×3×2=-36
```

此计算链以后用于反向传播；本日不展开完整神经网络。

### 2.5 机器人代价链

先用单参数例子说明 `u → p → J`：

```text
p=2u
J(p)=(p-2)²
dp/du=2
dJ/dp=2p-4=4u-4
dJ/du=(dJ/dp)(dp/du)=8u-8
```

在 u=0.5 时，p=1，dJ/du=-4，增大 u 会使 J 局部下降。这里 u 是可调整参数，不是底盘速度；若使用物理单位，p 与 u 的映射系数及更新步长应保持单位一致。

二维收口例子：

```text
u=[u_x,u_y]^T∈R²，单位 m
p(u)=[u_x,2u_y]^T，单位 m
q=[2,2]^T m
J(u)=(p_x-2)^2+(p_y-2)^2，单位 m²
u_current=[3,2]^T m，α=0.1 m^-2
```

通过链式法则分别求：

```text
∂J/∂u_x=2(p_x-2)×1=2u_x-4
∂J/∂u_y=2(p_y-2)×2=8u_y-8
∇_u J=[2,8]^T
u_new=[3,2]^T-0.1[2,8]^T=[2.8,1.2]^T
p_new=[2.8,2.4]^T
J_old=5，J_new=0.8
```

注意 `∇_u J` 与 `∇_p J` 不同：前者需要把位置对参数的影响通过链式法则乘进去。该例在 y 方向多出来的系数 2 是本日最后复测的关键。

### 2.6 工程连接与边界

SLAM：状态 → 预测观测 → residual → cost；轨迹优化：控制参数 → 预测轨迹 → 误差 → cost；深度学习：模型参数 → 输出 → loss。共同问题是最初变量变化如何影响最终目标。梯度下降是一种利用导数更新变量的方法；MPPI 主要通过采样轨迹与代价加权更新，不应混同为直接梯度下降。真实工程中的约束、坐标系、动态模型和控制接口需要单独处理，未读取的公司源码不作实现事实断言。

1. 初次将 `4(y-1)^2` 求成 `8y-4`，导致梯度误写 `[2,20]^T`；已纠正为 `8y-8`、`[2,16]^T`。
2. 方向导数一度写成 `J·d`；已纠正为 `∇J·d`，J 是标量，梯度才是敏感度向量。
3. 一度以为公式应使用加号，因为导数正时变量增大；通过 p=1 与 p=3 两侧比较，已区分代价上升与下降、梯度与负梯度的符号。
4. 对 α 的作用和引入动机不清楚；已纠正为先定义最小化目标，再由导数决定方向、α 控制更新幅度。
5. 原计算图题的箭头连写不易阅读；拆为独立的 z、w、L 定义及正向数值后，完成了链式法则说明。问题在题目表达，不应标成用户不会求导。
6. 机器人二维例子中将 `8u_y-8` 误写成 `4u_y-8`；首次收口得到 `[2,0]^T` 和 `[2.8,2]^T`。已纠正为内层 `p_y=2u_y` 的导数为 2，正确结果 `[2,8]^T`、`[2.8,1.2]^T`。
7. 最初综合题把梯度的用途关联到 Day13 noise/bias；已纠正为梯度主要提供优化变量对目标的局部敏感度，噪声和 bias 是另一个可靠性问题。
