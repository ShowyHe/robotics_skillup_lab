## 1. 今日核心

Attention（注意力）解决的问题：

\[
\boxed{
\text{一个 Token 应该从其他 Token 读取谁的信息，以及读取多少}
}
\]

主线：

\[
Token
\rightarrow
Q/K/V
\rightarrow
Attention\ Weight
\rightarrow
Weighted\ V
\rightarrow
New\ Token\ Feature
\]

---

## 2. Token 与 Embedding

Token 不只可以是文字，也可以是：
- Language Token（语言词元）
- Image Patch Token（图像块词元）
- Robot State Token（机器人状态词元）
- Action Token（动作词元）

Embedding（嵌入）把 Token 变成连续 Feature Vector（特征向量）。

---

## 3. Q / K / V

Q = Query（查询）：

\[
\boxed{\text{当前 Token 拿什么去查询}}
\]

K = Key（键）：

\[
\boxed{\text{其他 Token 拿什么特征与 Q 匹配}}
\]

V = Value（值）：

\[
\boxed{\text{匹配完成后真正提供的信息}}
\]

必须区分：

\[
\boxed{QK^T\text{负责“选谁”}}
\]

\[
\boxed{V\text{负责“拿内容”}}
\]

---

## 4. Q / K / V 的来源

对于输入：

\[
X\in\mathbb R^{n\times d_{model}}
\]

通过三个可学习投影：

\[
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
\]

其中 \(W_Q,W_K,W_V\) 都是 Parameter（参数）。

---

## 5. Attention Score（注意力分数）

若：

\[
Q\in\mathbb R^{n\times d_k}
\]

\[
K\in\mathbb R^{m\times d_k}
\]

则：

\[
QK^T\in\mathbb R^{n\times m}
\]

矩阵中第 \((i,j)\) 个元素：

\[
q_i\cdot k_j
\]

表示：

\[
\boxed{
\text{第 }i\text{ 个 Query 与第 }j\text{ 个 Key 的匹配分数}
}
\]

---

## 6. Softmax 与 Attention Weight

Scaled Dot-Product Attention（缩放点积注意力）：

\[
Attention(Q,K,V)
=
Softmax\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
\]

Softmax 后，每一行形成一组 Attention Weight（注意力权重），每行之和为 1。

它表示：

\[
\boxed{
\text{一个 Query 应该从各个 Key 对应的 Value 中分别读取多少信息}
}
\]

---

## 7. 为什么最后乘 V

如果 Attention Weight 为：

\[
[0.1,0.7,0.2]
\]

对应 Value：

\[
v_1,v_2,v_3
\]

则输出：

\[
0.1v_1+0.7v_2+0.2v_3
\]

因此只有乘 V 后，才真正把其他 Token 的内容取出并融合。

---

## 8. 为什么除以 \(\sqrt{d_k}\)

随着 Feature Dimension（特征维度）增大，Dot Product（点积）的数值幅度容易变大，使 Softmax 过度尖锐。

除以：

\[
\sqrt{d_k}
\]

主要用于控制 Score 的数值尺度，改善训练时的数值与 Gradient（梯度）行为。

---

## 9. Self-Attention / Cross-Attention

Self-Attention（自注意力）：

\[
\boxed{
Q,K,V\text{都来自同一个 Sequence（序列）}
}
\]

Cross-Attention（交叉注意力）：

\[
\boxed{
Q\text{来自一个 Sequence，}K,V\text{来自另一个 Sequence}
}
\]

例如 Language Token 作为 Q，Image Token 作为 K/V，就是语言从图像中读取视觉信息。

---

## 10. Multi-Head Attention（多头注意力）

多组不同的 Q/K/V Projection（投影）允许模型在不同 Feature Subspace（特征子空间）学习不同关系。

不能把每个 Head（注意力头）机械理解成固定负责某一种人类语义。

---

## 11. Positional Information（位置信息）

Self-Attention 本身不天然编码 Token 的顺序或图像 Patch 的空间位置。

因此需要 Positional Encoding / Positional Embedding（位置编码 / 位置嵌入）。

---

## 12. Transformer Block（变换器块）

典型组成：

\[
Attention
+
Residual
+
Normalization
+
FFN
\]

其中：

\[
\boxed{
Attention=\text{Token 之间交换信息}
}
\]

FFN = Feed-Forward Network（前馈网络）：

\[
\boxed{
FFN=\text{对每个 Token 自己的 Feature 做非线性变换}
}
\]

---

## 13. Causal Mask（因果掩码）

Autoregressive Model（自回归模型）中，当前 Token 不能读取未来 Token。

因此：

\[
Token_t
\]

只能访问：

\[
Token_{\le t}
\]

---

## 14. Robotics Connection（机器人连接）

后续 VLA（Vision-Language-Action，视觉语言动作）可形成：

\[
Image\ Tokens
+
Language\ Tokens
+
Robot\ State\ Tokens
\rightarrow
Transformer
\rightarrow
Action
\]

Attention 为不同模态之间的信息交换提供统一机制。
