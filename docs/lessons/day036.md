## 2. Metric Depth vs Relative Depth

Metric Depth（米制深度）具有真实物理单位，例如：

\[
Z=2.3m
\]

Relative Depth（相对深度）主要表达远近关系，不保证输出值本身就是米。

因此：

\[
\boxed{
Relative\ Depth\neq Metric\ Depth
}
\]

Relative Depth 不能未经尺度恢复直接写入米制导航空间。

---

## 3. Monocular Scale Ambiguity（单目尺度歧义）

针孔模型：

\[
x=f\frac{X}{Z}
\]

若：

\[
X\rightarrow2X,\qquad Z\rightarrow2Z
\]

则：

\[
f\frac{2X}{2Z}=f\frac{X}{Z}
\]

图像投影不变。

因此单张图像天然缺少 Absolute / Metric Scale（绝对 / 米制尺度）。

---

## 4. Learned Monocular Depth（学习式单目深度）

单目学习式深度不是只靠纯几何，而是从训练数据中学习 Visual Prior（视觉先验），例如：

- 物体典型尺寸
- 道路透视
- 纹理
- 遮挡关系
- 场景结构

因此可形成：

\[
Image
\rightarrow
Learned\ Prior
\rightarrow
Depth
\]

---

## 5. Scale Calibration（尺度标定）

对于 Relative Depth：

\[
\hat Z
\]

可通过 Metric Reference（米制参考）恢复尺度，例如：

\[
Z_{metric}=s\hat Z
\]

或某些模型使用更一般的：

\[
Z_{metric}=a\hat Z+b
\]

Metric Reference 可来自 LiDAR、RGB-D、Stereo 或已知距离目标。

---

## 6. Distribution Shift（分布漂移）

Learned Depth（学习式深度）依赖训练分布。

相机焦距、安装高度、视角、室内/室外、白天/夜晚、天气变化都可能造成：

\[
p_{train}(x)\neq p_{real}(x)
\]

因此即使模型输出单位是米，也不代表实机尺度永远准确。

---

## 7. Depth Edge（深度边缘）

物体前景与背景交界处可能出现深度突变。

例如：

\[
2m\rightarrow8m
\]

边缘 Pixel 容易发生：
- 前景背景混合
- 插值错误
- 无效深度
- 错误中间值

因此物体轮廓边缘深度通常应更谨慎使用。

---

## 8. BBox Center Depth 风险

Bounding Box（边界框）中心 Pixel 未必真正落在目标实体上。

例如中心点可能落在：
- 两腿之间背景
- 手臂空隙
- 另一个物体
- Depth Edge
- Invalid Depth

因此不能把单个中心点深度机械当作整个目标距离。

---

## 9. Mask / Multi-point Sampling

更稳的做法是：

\[
Mask
+
Valid\ Depth\ Filtering
+
Multi\text{-}point\ Sampling
\]

再使用 Median（中位数）、Percentile（分位数）或 Cluster（聚类）得到代表性目标深度。

例如：

\[
[2.0,2.1,1.9,2.0,8.0]
\]

Median：

\[
\boxed{2.0m}
\]

对异常值更稳健。
