## 2. PointCloud（点云）与 Point Fields（点字段）

点云是三维点集合。单个点除了 x/y/z，还可包含 Intensity（回波强度）、Timestamp（时间戳）、Ring（扫描线编号）、RGB（颜色）、Semantic Class（语义类别）、Confidence（置信度）。

机器人使用 3D 结果时必须明确：

Geometry + Frame + Timestamp

## 3. Organized / Unorganized PointCloud

Organized PointCloud（有组织点云）保留二维网格结构：

Pixel(u,v) ↔ Point(X,Y,Z)

典型 RGB-D 点云可保持 H×W 结构，因此保留像素邻接关系。

Unorganized PointCloud（无组织点云）只保留点列表，不天然保留二维网格邻接关系。

## 4. PointCloud Filtering（点云滤波）

- Crop / ROI Filter：只保留机器人关注空间。
- Range Filter：只保留有效距离范围。
- Outlier Filter：利用邻域点数量或空间统计去除孤立异常点。

## 5. Voxel Downsampling（体素降采样）

使用 Voxel Grid（体素网格）划分三维空间。

一个体素内多个点压缩为一个代表点：

Many Points in One Voxel → One Representative Point

Voxel Size 增大：

Point Count ↓
Computation ↓
Geometry Detail ↓

Voxel 是几何降采样，不是 Classification（分类），也不是 Clustering（聚类）。

## 6. Nearest Neighbor 与 KD-tree

Nearest Neighbor（最近邻）用于寻找空间上最近的点。

KNN = K-Nearest Neighbors（K近邻），寻找最近的 K 个邻居。

KD-tree = K-Dimensional Tree（K维树），通过递归划分空间建立 Spatial Index（空间索引），核心作用：

KD-tree = 加速 Neighbor Search（邻居搜索）

KD-tree 本身不是聚类算法。

## 7. Local Normal（局部法向量）

单个 3D 点不能定义表面方向，需要：

Neighbor Points
→ Local Plane
→ Normal

Surface Normal（表面法向量）后续用于 Point-to-plane ICP（点到平面迭代最近点）等算法。

## 8. Euclidean Clustering（欧氏聚类）

使用空间距离把同一团点连接成一个 Cluster（簇）。

Clustering Tolerance（聚类距离阈值）太小：

Over-segmentation（过分割）
→ 一个真实物体容易被拆成多个簇。

阈值太大：

Under-segmentation（欠分割）
→ 多个真实物体容易被合成一个簇。

Clustering 是几何分组，不等于 Classification（语义分类）。

## 9. DBSCAN

DBSCAN = Density-Based Spatial Clustering of Applications with Noise（带噪声的基于密度空间聚类）。

核心依赖邻域半径 epsilon 与最小邻居数量 min_samples。

直觉：

Distance + Local Density → Cluster / Noise

本日只要求理解概念，不深入算法推导。

Pixel + Semantic + Depth → 3D Semantic Point

点云由纯几何扩展为“几何 + 语义”。

## 11. 3D Bounding Box（三维边界框）

典型输出：

x, y, z, l, w, h, yaw, class, score

相比 2D Box，关键新增：
- 真实三维位置：x/y/z
- 物理尺寸：l/w/h
- 空间朝向：yaw
