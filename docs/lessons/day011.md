## 2. 今日核心重点

### 2.1 Eigen pair：特征向量与特征值是一对

对 `A∈R^(n×n)`，若存在非零向量 `v∈R^n` 与标量 `λ∈R`：

```text
Av = λv
```

则：
- `v`：eigenvector，A 的特殊方向；
- `λ`：eigenvalue，A 沿该方向的缩放系数；
- 特殊点：经过 A 后仍留在 `v` 所在直线上，不串到其他方向。

必须保持类型清楚：

```text
c, λ ∈ R          scalar
v, x ∈ R^n        vector
x = cv ∈ R^n
```

`x=cv` 只表示 x 位于 v 这条方向上，c 控制沿该方向的大小和正反方向。

### 2.2 特征向量不是为了“能拆”，而是为了“拆完后不耦合”

任意一组线性无关基都可以表示向量；特征向量的价值不是“只有它能拆向量”。

若二维 A 有两条线性无关特征方向：

```text
Av1 = λ1 v1
Av2 = λ2 v2
x = c1 v1 + c2 v2
```

其中 `c1,c2∈R`，则：

```text
Ax = c1 λ1 v1 + c2 λ2 v2
```

几何意义：
- 先把输入分解到两个特征方向；
- A 对 v1 分量只乘 λ1；
- A 对 v2 分量只乘 λ2；
- 最后重新合成。

一般向量 `x` 经过 A 后**通常会改变方向**，因为不同特征方向的缩放倍数不同，分量比例发生变化。只有纯特征方向 `x=cv` 才表现为单纯缩放/翻转。

### 2.3 为什么特征基下会出现对角矩阵

令：

```text
V = [v1  v2]
Λ = diag(λ1, λ2)
```

由：

```text
Av1 = λ1v1
Av2 = λ2v2
```

可得：

```text
AV = VΛ
```

若 V 可逆：

```text
V^-1 A V = Λ
```

因此在特征向量组成的新基下，A 的矩阵表示变为：

```text
[ λ1   0 ]
[  0  λ2 ]
```

两个非对角位置为 0 的真正原因是：
- v1 经过 A 后没有 v2 成分；
- v2 经过 A 后没有 v1 成分；
- 即两个特征方向在该表示下不发生耦合。

**这不是因为正交才为 0。** 只要有足够多线性无关特征向量，矩阵即可对角化。

### 2.4 实对称矩阵为什么更特殊

一般矩阵的特征向量不一定正交。

对实对称矩阵 `A=A^T`：
- 不同特征值对应的特征向量正交；
- 重复特征值的特征子空间中也可以选出正交单位特征向量；
- 因此可以构造正交矩阵 Q，使 `Q^-1=Q^T`；
- 得到正交对角化：

```text
Q^T A Q = Λ
A = Q Λ Q^T
```

集合关系：

```text
实对称矩阵 ⊂ 可对角化矩阵
```

“实对称”是更强条件；可对角化矩阵不一定对称。

### 2.5 离散系统中的 eigenvalue

对：

```text
x_(k+1) = A x_k
```

若状态位于某个特征方向：

```text
x_0 = cv
```

则：

```text
x_k = c λ^k v
```

直觉：
- `|λ|<1`：该方向逐步衰减；
- `|λ|>1`：该方向逐步放大；
- `λ<0`：每一步同时翻转方向；
- 例：`λ=-0.5` → 每步反向且幅值减半，长期趋近 0。

### 2.6 Quadratic Form

对 `x∈R^n, Q∈R^(n×n)`：

```text
J = x^T Q x
```

当 Q 为对称矩阵并换到其正交特征基后：

```text
x = c1v1 + c2v2 + ...
J = λ1 c1^2 + λ2 c2^2 + ...
```

原坐标中可能存在交叉项，例如：

```text
5x^2 + 8xy + 5y^2
```

换到特征方向后，交叉耦合被消掉，可以直接看到每个主方向的权重/曲率/方差。

### 2.7 Positive Definite

若对所有非零 `x`：

```text
x^T Q x > 0
```

则 Q 正定。

对 cost 的直觉：
- 零误差可取得 0；
- 任意非零误差产生正代价；
- 不会出现“误差越大 cost 反而变成负数”的方向；
- 因此很适合作为误差平方型 cost。

## 3. 工程应用重点

### 3.1 Covariance ellipse

对称协方差矩阵 `Σ` 的：
- eigenvector：不确定性的主方向；
- eigenvalue：该主方向上的**方差**；
- 1σ 轴尺度与 `sqrt(λ)` 成正比。

注意：`λ=9` 表示该方向方差为 9，不表示椭圆轴长直接等于 9；对应标准差为 3。

### 3.2 LQR / Quadratic cost

`J=x^TQx` 中，大 eigenvalue 表示沿对应特征方向 cost 增长更快。

固定同一 cost 的等高线时：
- eigenvalue 越大 → 该方向允许的误差距离越短；
- 因此 cost 等高线在“大 eigenvalue”方向反而更短。

### 3.3 Hessian

对称 Hessian 的：
- eigenvector：局部主曲率方向；
- eigenvalue：该方向曲率强弱。

这用于理解优化问题为什么某些方向“很硬”、某些方向“很平”。

## 4. 今日重要纠错

1. **类型没有标清**：最初 `x=cv` 未明确 c 是标量、v/x 是向量，导致表达不清。以后数学教学涉及混合类型时必须显式标 dimensions / scalar / vector。
2. **“特征向量是为了拆向量”不准确**：普通基也能拆；特征基特殊在变换后各方向不互相耦合。
3. **任意向量不是只做整体缩放**：不同特征分量按不同 λ 缩放后，合成方向一般改变。
4. **特征向量不一定正交**：一般矩阵不保证；实对称矩阵可选正交特征基。
5. **对角矩阵的两个 0 不是因为正交**：而是 eigen direction 变换后不产生其他 eigen direction 分量。
6. **“最大特征值 = 最大拉伸”不能推广到一般矩阵**：特征值只描述 eigen direction；一般矩阵真正的最大/最小长度拉伸由 singular value 描述。
7. **协方差 eigenvalue 不是椭圆轴长**：是方差，轴尺度与 `sqrt(λ)` 成正比。
8. 曾把“求秩时通过初等行变换把矩阵变简单”与 eigen diagonalization 混在一起；已区分：
   - Gaussian elimination / row reduction：改变矩阵表示以求 rank / solve equations，保留 rank 等性质；
   - Eigen diagonalization：换 basis 描述同一个 linear transformation，得到 `V^-1AV=Λ`。
