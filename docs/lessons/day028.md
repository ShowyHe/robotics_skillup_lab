## 2. Computational Graph（计算图）

[

[

## 3. Gradient（梯度）的含义

[
rac{partial L}{partial w}
]

表示：

[
oxed{	ext{Loss 对 Parameter }w	ext{ 的局部敏感度}}
]

它描述 (w) 微小变化时，Loss 如何变化。

- 偏导为正：(w) 增大时 Loss 局部倾向增大
- 偏导为负：(w) 增大时 Loss 局部倾向减小
- 绝对值较大：Loss 对该参数更敏感

---

## 4. Chain Rule（链式法则）

若：

[
wightarrow zightarrowhat yightarrow L
]

则：

[
oxed{
rac{partial L}{partial w}
=
rac{partial L}{partialhat y}
cdot
rac{partialhat y}{partial z}
cdot
rac{partial z}{partial w}
}
]

Backpropagation（反向传播）不是新的数学定理，本质是高效组织 Chain Rule。

## 7. Gradient Accumulation（梯度累加）

如果同一个变量通过多条路径影响 Loss，各路径梯度贡献需要相加。

例如两条路径贡献：

[
2,quad -0.5
]

则：

[
oxed{
rac{partial L}{partial x}
=
2+(-0.5)
=
1.5
}
]

## 8. Reverse-mode Automatic Differentiation（反向模式自动微分）

深度学习常见结构：

[
oxed{	ext{很多Parameter}ightarrow	ext{一个Scalar Loss}}
]

因此从单个 Scalar Loss 反向传播时，可以复用计算图里的中间结果，并高效得到大量 Parameter 的 Gradient。

不是“每个参数各自重新跑一条独立链”。

---

## 10. requires_grad / grad / no_grad / detach

- `requires_grad=True`：需要跟踪与该 Tensor 相关的梯度关系
- `.grad`：保存 Loss 对该 Parameter 的 Gradient
- `no_grad`：该区域不建立梯度跟踪
- `detach`：从当前计算图切断梯度关系

Inference（推理）通常不需要完整 Gradient Graph（梯度计算图）。
