## 2. Voxel Downsampling vs Voxel Representation

Voxel Downsampling（体素降采样）：
- 用 Voxel Grid（体素网格）切分空间；
- 一个体素内多个点压成一个代表点；
- 目的：减少 Point Count（点数），降低后续计算量。

Voxel Representation（体素表示）：
- 用体素网格表示整个 3D Space（三维空间）；
- 每个体素保存空间状态；
- 例如 Occupied / Free / Unknown。

核心边界：

Voxel Downsampling = 点云压缩
Voxel Representation = 世界空间表示

## 3. Occupied / Free / Unknown

Occupied（已占据）：
有观测证据表明该空间存在障碍。

Free（自由空间）：
有观测证据表明该空间被传感器射线穿过且未被阻挡。

Unknown（未知空间）：
没有足够观测证据说明它是 Free 或 Occupied。

Hard Gate：

Unknown != Free
No Point != Free

没有点不代表自由空间，可能只是未观测、被遮挡、超出量程或深度无效。

## 4. Ray Casting（射线投射）

LiDAR 一束光在 5m 处打到墙：

0～5m 中间射线经过区域 → Free
5m 墙面附近 → Occupied
墙后未观测区域 → Unknown

## 5. 2D Occupancy Grid（二维占据栅格）

移动机器人常将 3D 空间投影到地面 x-y 平面，形成 2D Occupancy Grid。

常见状态：
- Free
- Occupied
- Unknown

3D 点 / 体素可根据高度范围和规则投影到地面 Cell（栅格单元）。

## 6. BEV（Bird's-Eye View，鸟瞰图）

BEV 是从上方观察地面空间的表示方式。

BEV 可以装：
- Geometry（几何）
- Occupancy（占据）
- Semantic（语义）
- Learned Feature（学习特征）

因此：

BEV != Occupancy

BEV 是空间表示形式，Occupancy 是其中一种状态语义。

## 7. LiDAR → BEV

LiDAR 已有 x/y/z。

典型流程：

LiDAR Point
→ Frame Transform
→ Height Filter
→ Ground Projection
→ BEV Cell

## 8. Camera → BEV

Camera 直接输出 Pixel(u,v)，需要：

Pixel + Depth
→ Camera 3D
→ base_link
→ Ground Plane
→ BEV

因此 Day36 的 Depth 与 Day38 的 BEV 正式连接。

这使系统从“图像里哪里是 road/person”升级到“机器人周围实际空间哪里是 road/person”。

## 10. Semantic BEV vs Costmap

Semantic BEV 表达：
- 什么地方是什么语义；
- 世界空间长什么样。

Costmap 表达：
- 对当前机器人而言，该区域规划代价多高。

核心边界：

BEV = World Representation（世界表示）
Costmap = Planning Representation（规划表示）

## 11. Cost Mapping（代价映射）

Semantic BEV 不能直接等于 Costmap。

中间需要 Cost Mapping Rule（代价映射规则），例如：

person → lethal
road → low cost
grass → high cost
unknown → unknown / high risk

正确链路：

Semantic BEV
→ Cost Mapping / Rule / Fusion
→ Costmap

Inflation（膨胀）可以是后续 Costmap 处理，但不是语义变成代价的核心转换本身。

## 12. YOLO vs BEV

YOLO Detection（YOLO目标检测）主要描述 Object Level（目标级）信息：

“图像里检测到了什么物体”。

BEV 主要描述 Spatial Layout（空间布局）：

“鸟瞰空间里各区域是什么状态 / 语义”。

YOLO 结果可结合 Depth + TF 投影进入 BEV。

## 13. Occupancy Prediction（占据预测）

Neural Network（神经网络）可以直接从图像预测 BEV Occupancy（鸟瞰占据）。

但：

Prediction != Measurement Truth

仍可能受 Distribution Shift（分布漂移）、FP/FN、Calibration（标定）等影响。

## 14. Resolution / Range / Memory Trade-off

Resolution（分辨率）更细：

Geometry Detail ↑
Grid Count ↑
Memory ↑
Computation ↑

Range（范围）增大且 Resolution 不变：

Grid Count ↑
Memory / Computation ↑

## 15. Temporal Fusion（时序融合）与 Ego-motion（自运动）

多帧 BEV 可通过 Temporal Fusion 提升稳定性。

但机器人自身会移动，因此不能直接把旧 BEV 与新 BEV 原位置叠加。

正确链路：

Old BEV
→ Ego-motion Compensation（自运动补偿）
→ Transform to Current Frame（变换到当前坐标系）
→ Fusion

## 16. Coordinate Alignment（坐标对齐）

BEV 正确性不只依赖模型，还依赖：

Depth
+ Intrinsic
+ Extrinsic
+ Pose
+ Timestamp

外参错误、时间错位或位姿错误都会把正确感知投影到错误空间位置。
